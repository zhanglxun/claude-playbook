# 目标与定时任务

> 内容核对日期：2026-10-18；选学内容。部分功能为研究预览/公测，且按套餐和版本开放，请以官方文档为准。

**适合谁**：有周期性工作（日报、巡检、监控）或"要干到做完为止"任务的人。

**学完这页你能**：用 `/goal` 让 Claude 持续干到条件满足；用 `/loop` 在会话里定时重复；知道 Routines（云端例行任务）和桌面应用定时任务各适合什么，并按场景选对方式。

## 四种方式一览

| | `/goal` | `/loop` | Routines（云端） | 桌面应用定时任务 |
|---|---|---|---|---|
| 触发 | 上一轮结束后，条件没满足就继续 | 到了时间间隔 | 定时、接口调用或 GitHub 事件 | 到了设定时间 |
| 运行在 | 当前会话 | 当前会话（你的电脑） | Anthropic 云端 | 你的电脑 |
| 电脑要开着吗 | 要 | 要，且会话要开着 | 不用 | 要，且桌面应用要开着、电脑未休眠 |
| 能读本地文件 | 能 | 能 | 不能（云端拉取代码仓库） | 能 |
| 最短间隔 | 不适用 | 约 1 分钟 | 1 小时 | 1 分钟 |
| 典型用途 | 把一批工作做完 | 盯进度、定时检查 | 每晚固定产出 | 每天读本地文件做简报 |

选择口诀：**要做完用 goal；会话里盯着用 loop；电脑可能关机用 Routines；要用本地文件用桌面定时任务**。

## /goal：干到条件满足为止

`/goal` 设定一个"完成条件"。每轮结束后，另一个小模型会检查条件是否满足；没满足，Claude 自动开始下一轮，不用你每步催。条件满足、被判定不可能完成，或遇到需要你处理的错误时，目标会自动清除。

在 Claude Code 对话框里输入：

```text
/goal 【待办清单.xlsx 里每一行都已填写"处理结果"列，且没有空白行；最多进行 20 轮后停止】
```

写好条件的要点：

- 写成**能被看到的结果**：评审模型只看对话里 Claude 展示出的内容，不会自己去打开文件。
- 写明**怎么证明**（例如"列出空白行数量为 0"）。
- 加上**轮数或时间上限**，防止无限循环。

其他用法：单独输入 `/goal` 查看状态；`/goal clear` 清除目标。注意 `/goal` 不会改变权限模式——要让它无人值守地跑，需要配合自动模式，否则遇到需确认的操作仍会停下来问你。

## /loop：在会话里循环

`/loop` 让 Claude 每隔一段时间重复一个提示，适合轮询、盯进度：

```text
/loop 30m 检查【共享文件夹 inbox/】有没有新文件，有的话按模板整理成摘要告诉我
```

- 写了间隔就按固定节奏；不写间隔，Claude 会自己决定下次多久后再看（一分钟到一小时）。
- 循环任务**只在会话开着、Claude 空闲时触发**；关掉终端就停了。
- 循环任务**7 天后自动过期**，防止忘记关闭。
- 想停止，按 `Esc`（对自动节奏的循环）或让 Claude 取消。

## Routines：云端例行任务

Routines 是保存好的"提示词 + 代码仓库 + 连接器"，在 Anthropic 云端自动运行，**你的电脑关机也照常跑**。目前是**研究预览**，行为和限制可能变化；面向 Pro、Max、Team、Enterprise 套餐，Team/Enterprise 的管理员可以整体关闭。

- 触发方式：定时（每小时、每天、工作日、每周，或某个时间点一次）、接口调用、GitHub 事件。
- 创建：网页 claude.ai/code/routines，或在 Claude Code 里输入 `/schedule` 用对话方式创建，例如 `/schedule 每个工作日早上9点汇总昨日新增的客户反馈`。
- 云端运行**没有逐步确认**，是自主执行，所以提示词必须写得自包含、明确，并且只连接必要的连接器和代码仓库。
- 它属于你个人账号，不与同事共享；做的事会以你的身份出现（如发消息）。
- 用量与你的订阅共用；另有每小时运行次数上限，具体数字见[官方文档](https://code.claude.com/docs/en/routines)。

## 桌面应用定时任务

在 Claude 桌面应用的 **Code** 标签页，侧边栏点 **Routines** → **New routine** → 选 **Local**，就能创建在你电脑上运行的定时任务（需要较新的桌面版本）。它能直接读写本地文件，适合"每天早上读本地销售表生成简报"。

- 预设频率：手动、每小时、每天、工作日、每周；其他频率可对话让 Claude 设置。
- 只在桌面应用开着、电脑未休眠时运行；错过的运行，开机后只补跑最近一次。
- 每个任务可单独设置权限模式；首次建议点 **Run now** 试跑，把常用权限选"始终允许"，避免半夜卡在确认框。

## 动手任务

1. 在练习文件夹放 5 个文本文件，用 `/goal` 让 Claude "为每个文件生成一行摘要写入 summary.csv，直到文件数与行数一致，最多 10 轮"。
2. 用 `/loop 5m` 让它每 5 分钟报告一次该文件夹的文件数量，观察两轮后让它取消。
3. 对照上面的对比表，写下你工作中一件周期性任务应该用哪种方式，为什么。

## 小结

- `/goal` 管"做完"，`/loop` 管"重复"，Routines 管"电脑关机也要跑"，桌面定时任务管"要用本地文件"。
- 定时与循环类任务会持续消耗用量，建议先小范围试跑并设上限。
