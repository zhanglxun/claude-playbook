# Artifacts：把结果做成成品

学完这页，你能让 Claude 不只是"回答"，而是直接生成可以查看、修改、导出的成品，例如文档、演示稿、图表、小工具和网页。

## 是什么

普通对话里，Claude 的回答是一大段文字，很难直接拿去用。**Artifacts** 是对话旁边的一个独立展示区：Claude 把较完整的成果放在那里，你可以一边看、一边让它修改。成果会保存在侧边栏的 Artifacts 页面里，方便以后再找。

打个比方：对话是"和助理商量"，Artifacts 是助理交给你的"成品稿"。

## 能做出什么

| 类型 | 业务例子 |
|---|---|
| 文档 | 调研报告、方案、制度草稿 |
| 演示稿 | 汇报用的幻灯片初稿 |
| 单页网页 | 产品介绍页、活动邀请页 |
| 图表与看板 | 销售数据可视化、简单看板 |
| 流程图、示意图 | 业务流程、组织结构 |
| 小工具 | 报价计算器、问卷、清单 |

## 怎么用

1. 在对话里直接说出想要的成品，例如"帮我做一个……"。
2. Claude 生成后，成品会在右侧单独显示。
3. 继续在对话里提修改要求，成品会随之更新。
4. 部分类型可以直接在成品上编辑，例如选中文字让 Claude 修改。
5. 出现报错时，可以点"让 Claude 修复"之类的按钮（名称以实际界面为准）。

## 示范提示词

**做一个报价小工具**

```text
请帮我做一个简单的报价计算器网页（Artifact）：
- 输入：产品单价、数量、运费、折扣百分比；
- 输出：总价，并显示计算过程；
- 界面简洁，使用中文，数字保留两位小数。
这是内部练习用，示例数据请使用虚构的数值。
```

**把数据做成图表**

```text
下面是【某产品】过去六个月的销量（虚构数据）：【粘贴数据】
请生成一个折线图的 Artifact，标出最高点和最低点，并在图下方写三句话的趋势说明。
```

**做一份汇报文档**

```text
根据我们刚才的讨论，生成一份"【主题】调研汇报"文档。
结构：背景、关键发现（3 条）、建议、下一步。每部分不超过 150 字。
```

## 修改与迭代

直接用大白话提要求，一次改几处就好：

```text
把标题改成蓝色，表格增加一列"备注"，最后加一个"风险提示"小节。
```

不满意时可以说"回到上一个版本的样子，只改第二段"。如果成品越改越乱，也可以重新开始，把最终要求一次说清。

## 分享与导出

- 成品默认只有你自己能看。
- 根据类型，可以导出为 Word、PDF、PowerPoint 等常用格式，或选择分享（是否可用取决于套餐与功能版本）。
- 对外发布前，检查里面有没有敏感信息。

## 注意事项

1. **核对内容**：图表数字、计算结果、文字事实都可能出错，对外使用前必须人工核对。
2. **小工具仅作练习与内部辅助**：涉及报价、合同的，以正式系统和人工审核为准。
3. **不要放敏感数据**：特别是准备分享出去的成品。
4. 做出的"小工具"不等于正式软件，不适合直接处理重要业务。

## 课堂练习

1. 用虚构数据，让 Claude 生成一个折线图 Artifact。
2. 连续提三次修改要求（改颜色、加标注、加一段说明）。
3. 尝试导出或保存，体验从"对话"到"成品"的过程。

## 小结

- Artifacts 让 Claude 直接交付可用的成品，而不只是文字回答。
- 先说清要什么，再逐步修改。
- 成品要核对，分享前要检查敏感信息。
