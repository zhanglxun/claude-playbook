## 一、哪些资料不要上传

默认原则：**不确定能不能传，就当作不能传，先问公司负责人。**

| 类别 | 例子 |
|---|---|
| 涉密信息 | 国家秘密及涉密信息，以及公司按制度定为"机密"的资料 |
| 个人敏感信息 | 身份证号、银行卡号、住址、电话、病历、人脸等生物识别信息 |
| 商业核心 | 底价、成本构成、未公开合同条款、未发布产品资料、源代码核心逻辑 |
| 凭证类 | 密码、API 密钥、令牌、验证码、数据库连接串 |
| 他人资料 | 客户、供应商交给你但约定保密的文件；受保密协议约束的内容 |
| 受监管数据 | 受行业或当地法规限制出境、出域的数据 |

## 二、脱敏：把敏感信息换成代号

脱敏就是在上传前，把真实的名字、数字换成不会泄露身份的代号。分析结果出来后，你再自己替换回去。

| 原文 | 脱敏后 |
|---|---|
| 客户全名 | 客户 A、客户 B |
| 具体人名与邮箱 | 联系人甲、[邮箱已隐藏] |
| 具体金额 | 区间或比例（如"约 8 万"改为"X"，或只保留涨跌百分比） |
| 内部项目代号 | 项目 P1 |
| 地址、电话 | 删除，或只保留城市 |

示例（虚构）：

```text
原文：向宏远电子（联系人王某，wang@example.com）报价 12.8 万元，交期 45 天。
脱敏：向客户 A（联系人甲）报价 X 元，交期 45 天。
```

你可以让 Claude 帮你检查是否漏脱敏，但**检查本身也要在脱敏后的文本上进行**：

```text
下面是我准备上传的文字。请只列出其中仍可能识别个人或企业的信息（人名、公司名、邮箱、电话、金额、地址），不要复述这些内容的原值，用位置描述即可。
```

小提示：Excel 文件除了单元格，还要检查隐藏的工作表、批注、文件属性里的作者名。

## 三、对话与项目中的数据管理

- **对话**：不再需要的对话可以删除；敏感话题用完即删。账号设置中的数据与隐私选项以官方页面说明为准。
- **Projects**：项目知识库里的文件会长期保留并被反复使用，只放脱敏后的、确认可共享的资料。团队共享的项目，要先想清楚谁能看到。
- **连接器与外部应用**：连接邮箱、云盘等应用前，先确认授权范围；只授权需要的内容，不用时断开。
- **记忆与个性化设置**：如果启用了记忆类功能，不要让它记下敏感信息；定期查看并清理。
- **导出与分享**：把对话或成品分享给他人前，再检查一遍是否含有敏感内容。
- **事后补救**：如果误传了敏感资料，删除对话，并向公司负责人报告；不要自行判断"应该没事"。

## 四、Claude Code 的权限与文件安全

Claude Code 能读、改你电脑上的文件，所以更要小心。详见 [权限与安全](/advanced/permissions)。要点：

1. **只在指定文件夹里工作**：从工作文件夹启动，不要在放着个人资料、公司全盘文件的目录里启动。
2. **原始资料做备份**：让它处理前先复制一份，或用版本管理；原件放进"只读"约定（在 CLAUDE.md 中写明）。
3. **危险操作先看再批准**：删除、覆盖、批量改名、发送外部内容，先让它列出计划再确认。大任务先用规划模式。
4. **了解权限模式**：每步确认最稳；自动批准的范围越大，越要保证文件夹里没有不该被动的东西。
5. **敏感文件不进工作区**：密钥、账号表、`.env` 类文件不要放在工作文件夹；可在权限设置里明确禁止读取。
6. **谨慎安装外部扩展**：来源不明的插件、MCP 服务、技能，等同于给陌生程序电脑权限；只装可信来源，并看清它要什么权限。参见 [MCP 与连接](/advanced/mcp)、[Skills 技能](/advanced/skills)。
7. **留意外部内容里的"指令"**：网页、文档、邮件中可能夹带"诱导 AI 执行操作"的文字。发现 Claude 突然要做与任务无关的事，拒绝并停下。
8. **定期查看改动**：任务结束后核对它改了哪些文件；需要时可回退，参见 [命令与快捷操作](/advanced/commands)。

## 五、公司内部使用规范建议清单

可作为制定公司制度的起点，按实际情况增删：

- [ ] 明确哪些业务可以使用 AI、哪些不可以。
- [ ] 明确资料分级，规定每一级能否上传。
- [ ] 要求上传前脱敏，并指定负责人解答"能不能传"。
- [ ] 一人一号，不共享、不转借、不转售账号；开启两步验证，参见 [账号安全设置](/guide/account-security)。
- [ ] 对外发布的内容（邮件、报告、宣传）必须由人审核后再用。
- [ ] 涉及数据、法规、医疗、法律、财务的结论，必须用权威来源核实，参见 [AI 的能力与局限](/guide/limits)。
- [ ] 重要成果注明"由 AI 辅助生成"的规则（按公司和行业要求）。
- [ ] 团队共享的 Projects、CLAUDE.md、技能由专人维护，定期清理。
- [ ] 离职、转岗时回收访问权限与共享内容。
- [ ] 发生泄露或账号异常时的上报流程与联系人。
- [ ] 定期培训并更新本清单。

## 六、合规提醒

- 遵守你所在地的法律法规，以及 Anthropic 的使用政策与服务条款。服务的可用地区、适用条款以官方说明为准。
- 涉及个人信息，要符合所在地个人信息保护要求，如告知、同意、最小必要等。
- 不用 Claude 生成违法、欺诈、侵权或误导他人的内容；对外使用内容要尊重版权和商标。
- 生成内容的准确性与后果由使用者负责，Claude 的输出不能替代专业意见。
- 本教程不提供也不鼓励任何规避地区限制或平台规则的做法。
- 遇到账号受限、无法使用等情况，请查看官方通知邮件，并通过官方帮助中心的渠道处理，参见 [常见问题](/faq/)。
