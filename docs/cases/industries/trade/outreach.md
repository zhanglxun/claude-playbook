# 客户开发信与跟进

开发信的难点不是写出一封邮件，而是**写出对方愿意回复的邮件，并持续、有节奏地跟进。** Claude 可以帮你起草、改写、做多个版本，但是否合适要由你判断。

> 案例为虚构：某家居出海品牌向"示意客户 A"（海外家居零售商）开发新客户。所有名称均为示意。

## 分析框架

写之前先想清楚五件事，缺哪项就先补哪项：

1. **对方是谁**：行业、规模、主营品类（来自其公开网站，不是内部资料）。
2. **为什么找他**：我们的产品与他的哪类需求匹配。
3. **我们能提供什么**：一个具体的价值点，而不是泛泛的"优质低价"。
4. **希望对方做什么**：一个明确的小动作，如回复确认、索取样品目录、预约 15 分钟沟通。
5. **跟进怎么安排**：第几天、用什么新角度再联系。

## 示范提示词

### 一：首封开发信

```text
你是一名经验丰富的外贸业务员。请写一封英文开发信。

我方信息：
- 公司：【公司简介，一句话】
- 产品：【产品名称与 2 个核心卖点】
对方信息（来自其公开网站）：
- 类型：【如：北欧在线家居零售商】
- 主营：【对方主营品类】
目的：【希望对方回复，了解产品目录】

要求：
- 150 词以内，开头一句说明为什么联系他，不要空洞客套
- 只写资料中的事实，不要编造合作经历、证书或数据
- 结尾给出一个明确的行动请求
- 提供 3 个不同风格的邮件标题备选
- 用英文输出邮件，再附一段中文说明各部分的用意
```

### 二：设计跟进节奏

```text
针对上面这封开发信，请设计一个 4 封邮件的跟进序列：
- 列出每封的发送时间（距上一封几天）、主题、新增的价值点
- 每封 80 词以内，每封都要有新角度（如案例、新品、行业话题），不要只写"跟进一下"
- 对方一直没回复时，最后一封写成礼貌收尾
用表格给出序列概览，再逐封给出英文正文。
```

### 三：根据回复调整

```text
对方回复如下（已脱敏）：
【粘贴对方回复内容】
请：
1. 判断对方的态度和关心点（用一两句话概括）
2. 起草回复，回答他的问题，不承诺我没有提供的内容
3. 列出需要我确认后才能回复的信息（如价格、交期）
```

## 课堂练习

1. 用虚构公司和产品，完成首封开发信，并让同伴扮演客户回复。
2. 根据回复，用提示词三起草第二封邮件。
3. 对比一封"泛泛的"开发信与按框架写的开发信，讨论区别。

## 注意事项

- **价格和承诺必须人工确认**：邮件里出现的价格、折扣、交期、样品政策，由你确认后再发，不要直接使用 Claude 写出的数字。
- **客户资料先脱敏**：用于提示词的对方信息只用公开信息；已有客户的真实联系方式、历史合同金额不要直接粘贴。
- **遵守当地邮件营销规定**：群发前了解目标国家对商业邮件的要求，以官方规定为准。<!-- TODO 核实：各主要市场商业邮件法规，建议链接官方页面后补充 -->
- 批量发送前，一定抽查几封，确认没有串错对方名称或事实。

## 两种做法对照

### 网页版做法

- 把公司和产品简介、语气要求放入 [Projects](/basics/projects) 的项目指令，每次只需粘贴对方公开信息。
- 一封一封起草并对话修改，质量可控。
- 适合：每天几封、需要个性化打磨。

```text
按项目指令中的公司简介和语气要求，为下面这位潜在客户起草首封开发信（英文，120 词以内），并给出 3 个标题备选。对方信息：【公开网站摘要】
```

### Claude Code 做法

- 把潜在客户清单（Excel，已脱敏，只含公司名、网站摘要、品类）放进文件夹，让它为每一行起草个性化邮件。
- 输出一张表加一个邮件草稿文件夹，你逐封审阅修改，**不让它自动发送**。
- 把公司简介、禁止承诺事项写入 `CLAUDE.md`；开发信流程固化为 [Skills](/advanced/skills)。

```text
请读取 客户线索/线索清单.xlsx（列：公司、国家、主营品类、网站摘要），
参考 资料/公司与产品简介.docx，为每家公司写一封英文开发信（120 词以内，个性化引用其主营品类）。
把所有草稿汇总到 开发信草稿.xlsx（列：公司、标题、正文、需人工确认事项），
并为每封邮件另存一个文本文件到 草稿/ 文件夹。
不要编造任何价格、证书或合作经历；只生成草稿，不要发送。
```

了解更多：[Claude Code 是什么](/advanced/what-is-claude-code)、[Skills](/advanced/skills)。

## 小结

好开发信 = 看清对方 + 一个具体价值点 + 一个明确请求。Claude 帮你提速，但价格承诺和群发合规由你把关。
