## 账号与套餐

### 免费版、个人付费和团队版怎么选？

看用量和协作需求：偶尔使用可先试免费版；每天高频使用再考虑个人付费；多人共享资料、需要统一管理时看团队类套餐。各套餐的功能和价格以官方页面为准，思路见 [账号类型怎么选](/guide/plans)。

### 提示额度用完了怎么办？

额度有重置周期，可以等待重置，或评估升级账号类型。平时可以通过"一次说清需求、少传无关长文件、新话题新开对话"来节省额度。具体规则看官方说明。

### 账号无法登录或被限制了怎么办？

不要反复尝试登录或重复注册。先查看邮箱里有没有官方通知，了解原因；然后按官方帮助中心提供的申诉或联系渠道处理。平时开启两步验证、保持登录环境稳定，参见 [账号安全设置](/guide/account-security)。

### 一个账号可以多人共用吗？

不可以，建议一人一号，也不要转借、转售账号。多人使用请选用适合团队的套餐，并遵守官方服务条款。

## 提示词与结果质量

### Claude 的回答一定准确吗？

不一定。它可能一本正经地说错（俗称"幻觉"）。涉及数据、法规、价格等关键信息时，请通过权威来源核实，并让它给出出处。详见 [AI 的能力与局限](/guide/limits)。

### 回答太长、太泛怎么办？

在提示词中明确格式和字数，例如"用 5 条要点回答，每条不超过 30 字"。也可以补充背景和读者，让它知道"写给谁看"。更多写法见 [提示词写法](/basics/prompting)。

### 同样的问题，每次答案不一样，正常吗？

正常。它的生成带有随机性。想要稳定的格式，就给出范例或模板，或把规则放进 Projects 的项目指令。

### 聊久了它好像"忘了"前面的要求？

对话越长，早期内容越容易被忽略，这与"上下文窗口"有限有关。办法：把关键要求重新贴一次；或者让它先总结已确认的要点，新开一个对话继续。

### 要不要说"请""谢谢"？

不影响能力，随你习惯。重点是把任务、背景和要求说清楚。

## 文件与数据

### 上传的文件安全吗？

请参考官方隐私政策，并遵守 [使用规范与数据安全](/security/)：不上传敏感信息，先脱敏再上传。不确定的先问公司负责人。

### 表格里的数字能直接信吗？

不能直接信。让它写出计算方法，并抽查几个数字对照原表。大表格可以先让它复述"看到了哪些列、多少行"，确认无误再分析。见 [文件与表格分析](/basics/files)。

### 文件太大传不上去，或读得不完整？

大文件可拆成几个部分，或只上传相关章节；扫描件图片质量差时识别会出错，建议先确认它读到的内容。文件大小和数量限制以官方说明为准。

### Projects 里的资料什么时候用？

长期要反复引用的资料（产品手册、模板）放 Projects，一次性的资料直接在对话里上传即可。参见 [Projects 项目功能](/basics/projects)。

### 能联网查资料吗？怎么保证来源可靠？

在支持的情况下可以开启联网搜索或深度研究。要求它列出网址和日期，你再点开核对。参见 [联网搜索与深度研究](/basics/research)。

## Claude Code

### 我不懂编程，能用 Claude Code 吗？

可以。本教程讲的是让它在你的电脑上读文件、整理资料、写报告，不需要写代码。入门见 [Claude Code 是什么](/advanced/what-is-claude-code)。

### 它会不会误删我的文件？

它做的操作默认会请求你的确认，也可以只授权在指定文件夹内工作。建议：重要文件先备份，大任务先让它给方案，批准后再执行。见 [权限与安全](/advanced/permissions)。

### CLAUDE.md 和 Projects 的指令有什么区别？

Projects 在网页端/桌面端，用来保存知识库和项目指令；CLAUDE.md 是放在电脑文件夹里的文本文件，供 Claude Code 每次启动时读取。思路相同，位置不同。见 [CLAUDE.md 记忆文件](/advanced/claude-md)，模板见 [Claude Code 模板](/prompts/claude-code)。

### 对话变慢、变"笨"了怎么办？

可能是上下文占满了。可以用 `/compact` 压缩对话，或用 `/clear` 开始新对话，用 `/context` 查看用量。见 [上下文与用量](/advanced/context-usage)。

### 应该选哪个模型？

简单、重复的任务选更快的模型；复杂分析、长文档选更强的模型。各模型定位见 [模型选择与推理强度](/advanced/models) 和 [术语表与速查表](/reference/)。

### 安装或启动报错怎么办？

先按 [安装与启动](/advanced/install) 检查，也可以在 Claude Code 里运行 `/doctor` 做体检。仍无法解决时查看官方文档或联系服务顾问。

## 安全与合规

### 哪些东西绝对不能输入？

涉密信息、个人敏感信息、公司核心商业秘密、各类密码和密钥。详见 [使用规范与数据安全](/security/)。

### AI 生成的内容可以直接对外发布吗？

不要直接发。请经人工核实事实、检查语气和合规后再使用，并遵守公司和行业对标注 AI 辅助的要求。

### 误上传了敏感资料怎么办？

立刻删除相关对话，并向公司负责人报告，由其按内部流程处理。以后上传前先脱敏。

不是。本教程为独立编写的培训内容，产品功能和政策以 Anthropic 官方文档为准。
