# 概念地图（一页纸）

学完这页，你能用一句话说清课程里反复出现的几个新名词，知道它们分别在哪一篇学。

先"认识"就行，不用现在就会用。

## 一页纸速查

| 概念 | 一句话说明 | 打个比方 | 在哪学 |
|---|---|---|---|
| 提示词 | 你输入给 Claude 的那段话 | 给同事布置任务的说明 | 基础篇 |
| 命令（斜杠命令） | 以 `/` 开头的快捷指令 | 软件里的快捷键 | 基础篇、高级篇 |
| Projects（项目） | 把资料和要求固定保存的"工作空间" | 一个项目文件夹加一份项目说明 | 基础篇 |
| Artifacts | 对话里生成的可查看、可修改的成品，如网页、图表、文档 | 助手交来的成品 | 基础篇 |
| Skills（技能） | 可复用的"做事手册" | 岗位操作手册 | 基础篇、高级篇 |
| MCP | 给 AI 接上"外接设备"，连接日历、云盘等外部工具 | 电脑的 USB 接口 | 基础篇、高级篇 |
| Agent（智能体） | 会自己拆步骤、一步步完成任务的 AI | 能独立跑完整个流程的助理 | 基础篇、高级篇 |
| Claude Code | 能在你电脑上读写文件、执行任务的版本 | 坐到你电脑前帮你干活的助手 | 高级篇 |

## 它们怎么串起来

```text
提示词（你说什么）
   ↓
Claude（大模型：思考与生成）
   ├─ Projects：记住长期背景和资料
   ├─ Skills：按固定流程做事
   ├─ MCP：连接外部应用和数据
   └─ Agent：自己拆步骤、连续完成

→ Artifacts：产出可用的成品
```

## 分层学习

| 概念 | 入门篇（认识） | 基础篇（会用） | 高级篇（用好） |
|---|---|---|---|
| 命令 | 快捷指令 | 网页端常用指令 | Claude Code 常用命令、自定义命令 |
| Skills | 做事手册 | 启用和使用 | 编写和管理 |
| MCP | 外接设备 | 连接常用应用 | 配置和使用 |
| Agent | 会拆步骤的 AI | 体验研究、分析任务 | 循环处理业务任务 |

## 课堂练习：自己说一遍

让 Claude 当考官，检验你是否真正理解：

```text
请用提问的方式考考我，对象是完全不懂技术的业务人员。依次问我这些概念是什么意思：提示词、Projects、Artifacts、Skills、MCP、Agent。我回答后你再点评并补充，每次只问一个。
```
