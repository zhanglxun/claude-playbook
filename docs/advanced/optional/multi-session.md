# 多会话并行与 Agent 视图

> 内容核对日期：2026-10-18；选学内容。部分功能为研究预览/公测，且按套餐和版本开放，请以官方文档为准。

**适合谁**：经常同时推进多件事、希望"派出去就不管，有事再叫我"的人。

**学完这页你能**：用 `claude agents` 在一个界面里看所有后台会话；用 `/fork` 分出一个新会话；让会话转到后台继续跑；了解会话之间如何互相传话。

## 先分清几个说法

- **会话**：一次独立的 Claude Code 对话，有自己的上下文。
- **后台会话**：不占着你的终端窗口、自己继续运行的会话。
- **Agent 视图**：一个屏幕，列出你所有后台会话的状态。目前是**研究预览**，界面和快捷键可能改变。
- 与 3.11 的"子代理"不同：子代理是一个会话内部的助手；这里说的是**多个独立会话**。

## Agent 视图：一屏管所有会话

在系统终端（不是 Claude Code 对话框里）输入：

```text
claude agents
```

如果打开的只是子代理列表而不是视图，先运行 `claude update` 升级。

视图里的会话按状态分组：**需要你输入**、**运行中**、**已完成**、**待审阅**。

- 派任务：在底部输入框写下任务回车，每条都会新开一个独立会话。可加前缀：`@代理名` 指定自定义子代理，`/技能名` 调用技能。
- 命令行直接派：`claude --bg "任务描述"`，直接在后台启动。
- 查看：选中一行按空格键，可"偷看"最新输出或它在等你回答的问题，并直接回复。
- 进入：按 Enter 或右方向键进入完整会话；按左方向键（输入框为空时）退出，**退出不会停止后台会话**。

从视图派出的会话会先进入各自独立的 git 工作树（独立文件副本）再改文件，避免多个会话互相覆盖。

## /fork 与 /background

在一个正在进行的会话里输入：

- `/background`（可简写 `/bg`）：把当前对话转到后台继续跑，你腾出窗口做别的。
- `/fork`：把当前对话**复制**成一个新的后台会话，原会话继续。适合"同样背景，换个思路再试一次"，如对同一份调研分别试两种分析角度。复制整个会话的 `/fork` 需要 Claude Code v2.1.212 或更高版本。

转入后台时，对话、后台命令和定时循环会带过去；正在运行的监控会被停掉，动态工作流里的子代理会从头重来（会再花一次用量），所以转后台前 Claude Code 会弹窗确认。

## 会话之间互相传话

多个会话同时工作时，一个会话发现的事可能影响另一个。**跨会话消息**允许 Claude 把一段文字发给你的其他会话，例如"数据表结构已改完，可以接着做了"。要求 Claude Code v2.1.224 或更高版本（Windows 原生环境为 v2.1.234）；满足条件即自动开启。

你不用自己调用什么，只需在对话里说：

```text
告诉【另一个终端里做报价核对的会话】：产品价格表已经更新完了
```

也可输入 `@` 加会话名来指定对象。需要了解的几条：

- 传的只是一段文字，不会传对话历史或文件。
- 收到消息的会话把它当作"另一个会话的来信"，**不算你的授权**：不能替你批准权限、不能改设置，消息里的斜杠命令也不会被执行。
- 消息在本机内通过本地通道传递，不经过 Anthropic 服务器；与其他电脑或云端会话之间的消息则要经过服务器。
- 输入 `/list-agents` 可以看到当前能联系到哪些会话。
- 不想收：把设置项 `crossSessionInbound` 设为 `refuse`（也可在 `/config` 里调整）。

## 动手任务

1. 在终端输入 `claude --bg "总结当前文件夹里有哪些文件，写成一段话"`，然后输入 `claude agents` 找到它。
2. 在视图里再派一条不同的任务，空格键查看两条的进展，观察状态分组变化。
3. 在一个进行中的会话里输入 `/fork`，对分叉出的会话追问一个不同的问题，比较两个结果。

## 小结

- `claude agents` 是"总控台"，适合同时推进多件互不相关的事。
- `/bg` 转后台，`/fork` 复制分叉。
- 会话间传话只传文字，且不能代替你授权。
- 多会话并行会成倍消耗用量，量力而行。
