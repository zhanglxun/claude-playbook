# 游戏行业

> **预留，内容后续补充。** 本页只说明计划涵盖的方向，不是完整教程。

游戏行业的文字类工作很多：玩家反馈、运营文案、本地化、策划文档。后续补充时，同样遵循"分析框架、示范提示词、课堂练习、两种做法对照"的结构，案例使用虚构游戏。

## 计划涵盖的高频场景方向

1. **玩家反馈与评论归纳**：把公开评论和社区反馈按主题分类，提炼高频问题与需求。
2. **运营与活动文案**：起草公告、活动说明、商店页描述，保持统一语气和世界观设定。
3. **多语言本地化初稿**：按术语表翻译与改写，列出存疑之处供本地化人员校对。
4. **策划文档整理**：把零散的玩法设想整理成结构化文档，列出待决策的问题。
5. **竞品与市场观察**：对公开的同类游戏信息做对比整理（方法与[竞品对比](/cases/common/competitor)一致）。

## 使用前提醒

- 未发布的剧情、数值、素材属于机密，不要上传。
- 玩家评论仅使用公开可见内容，并遵守相关平台规则。
- 面向玩家的文案须经人工审核后再发布。
