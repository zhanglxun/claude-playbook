# 提示词写法

## 好提示词的四个要素

| 要素 | 说明 | 例子 |
|---|---|---|
| 角色 | 让 Claude 以什么身份回答 | 你是一名有 10 年经验的外贸业务经理 |
| 背景 | 提供必要的上下文 | 我们是做家居用品出口的，主要市场是欧洲 |
| 任务 | 明确要做什么 | 帮我分析这款产品在德国市场的卖点 |
| 格式 | 规定输出的样子 | 用表格列出，每条不超过 30 字 |

## 实用技巧

- **给例子**：给出一个你想要的样例，效果远好于描述
- **分步骤**：复杂任务拆成几步，一步一步来
- **让它先问**：不确定时加一句"如有信息不足，请先向我提问"
- **追问修改**：第一次结果不满意，直接说哪里要改，不必重写

## 课堂练习

用四要素改写这句提示词：「帮我写个产品介绍」。
