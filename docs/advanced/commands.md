# 命令与快捷操作

> 内容核对日期：2026-10-18；涉及的功能以 Claude Code 当时版本为准，请以官方文档为准。

## 学完这页你能…

- 说清什么是斜杠命令，会用 `/` 菜单查找命令
- 记住十来个最常用的命令及其用途
- 用"技能文件"自己写一个自定义命令
- 掌握几个最省事的快捷键，知道怎么自定义

## 一、什么是斜杠命令

**斜杠命令**是以 `/` 开头的快捷指令。你在输入框里敲 `/`，会弹出一个菜单，列出当前能用的命令；继续输入字母可以筛选。

和普通对话的区别：普通对话是"说一句话让 AI 理解"，斜杠命令是"直接按一个按钮"，例如清空对话、切换模型、查看用量，不需要 AI 去琢磨。

几个规则：

- 命令必须写在消息的**开头**才被识别，命令后面的文字会作为参数，比如 `/plan 整理访谈记录`
- Claude 正在工作时发出的命令，多数会排队，等当前这一轮结束再执行；少数命令（如 `/status`、`/usage`）会立即执行
- 并不是每个命令都对所有人可见，取决于你的平台、套餐和使用入口。**VS Code 面板里只有命令的一部分**，终端里最全
- 忘了怎么用时，输入 `/help` 查看

## 二、最常用的命令

按"一个工作流程中什么时候用"来记：

### 开始工作

| 命令 | 用途 |
|---|---|
| `/init` | 为当前文件夹生成一份起始的 CLAUDE.md（业务说明书），详见 [3.6](/advanced/claude-md) |
| `/memory` | 查看和编辑 CLAUDE.md 与自动记忆 |
| `/permissions` | 管理"允许、询问、禁止"的权限规则，详见 [3.5](/advanced/permissions) |
| `/model` | 切换模型，详见 [3.8](/advanced/models) |

### 工作过程中

| 命令 | 用途 |
|---|---|
| `/plan 任务` | 进入 Plan 模式，先出方案 |
| `/context` | 用彩色格子显示上下文用掉了多少 |
| `/compact` | 把前面的对话压缩成摘要，释放空间 |
| `/btw 问题` | 问一个"旁白问题"，答案不会加进正在进行的对话 |
| `/diff` | 查看你的工作文件夹相比之前改了什么，包括 Claude 做的修改 |
| `/effort` | 调整推理强度（想得多深） |

### 换任务与回退

| 命令 | 用途 |
|---|---|
| `/clear` | 开始全新对话，清空上下文（别名 `/reset`、`/new`），旧对话可用 `/resume` 找回 |
| `/resume` | 回到之前的某次对话 |
| `/rewind` | 回退文件与对话（别名 `/undo`、`/checkpoint`），详见 [3.3](/advanced/daily-use) |
| `/rename 名字` | 给当前对话起名，方便以后找 |
| `/branch` | 在当前位置分出一个分支，试另一个方向，原对话保留 |

### 查看状态与排查

| 命令 | 用途 |
|---|---|
| `/usage` | 查看用量，`/cost` 是它的别名，详见 [3.7](/advanced/context-usage) |
| `/status` | 查看版本、模型、账号和连接状态 |
| `/doctor` | 做一次"体检"，诊断安装和设置问题，确认后可以自动修复 |
| `/login` / `/logout` | 登录、退出账号 |
| `/powerup` | 通过互动小课程发现功能 |

## 三、技能和命令的关系

你可能注意到菜单里有些命令不是内置的，而是"技能"（Skills）。官方说明：**自定义斜杠命令现在就是技能**。两者创建出来的 `/名字` 用法完全一样。技能的完整讲解见 [3.9 Skills](/advanced/skills)，这里只讲怎么做一个最简单的自定义命令。

## 四、自定义命令：把常用提示词做成按钮

如果你每周都要说同一段话，比如"按我们的格式整理本周的行业新闻"，就可以把它做成命令。

### 放在哪里

| 范围 | 位置 | 谁能用 |
|---|---|---|
| 个人 | `~/.claude/skills/命令名/SKILL.md` | 你电脑上的所有项目 |
| 项目 | 工作文件夹内的 `.claude/skills/命令名/SKILL.md` | 这个文件夹（随文件夹共享给同事） |
| 旧格式 | 工作文件夹内的 `.claude/commands/命令名.md` | 仍然支持 |

> 说明：`~` 代表你的个人主目录；以点开头的文件夹（如 `.claude`）在系统里默认隐藏，在 VS Code 左侧文件列表里可以看到。

### 一个业务例子

在工作文件夹里新建文件 `.claude/skills/weekly-news/SKILL.md`，内容如下：

```markdown
---
name: weekly-news
description: 把一批行业新闻整理成一页周报摘要
argument-hint: [文件夹名]
disable-model-invocation: true
---

请阅读 $ARGUMENTS 文件夹中的所有新闻文件，整理成一页周报摘要：

1. 先列"本周三大要点"，每条不超过 40 个字
2. 再按"政策、竞争对手、客户动态"三类分别汇总
3. 每条信息注明来源文件名
4. 如果某类没有内容，写"本周无"，不要编造
5. 保存为"周报-本周.md"
```

之后在输入框里输入 `/weekly-news 本周新闻`，Claude 会把"本周新闻"代入 `$ARGUMENTS`，按上面的要求执行。

各字段的意思：

| 字段 | 作用 |
|---|---|
| `name` | 命令名，默认取文件夹名 |
| `description` | 描述这个命令做什么、何时用 |
| `argument-hint` | 输入时的提示，告诉别人要传什么 |
| `disable-model-invocation: true` | 只有你手动输入才会运行，Claude 不会自己调用。对有"副作用"（会改文件）的流程建议设置 |

这类写法的一个小门槛是要创建带"---"开头的文本文件。你也可以直接让 Claude 帮你写："请帮我创建一个叫 weekly-news 的自定义命令，作用是……"。

## 五、常用快捷键

下表以终端为准。VS Code 面板里的快捷键略有不同，列在最后。

| 快捷键 | 作用 |
|---|---|
| `Shift+Tab` | 循环切换权限模式 |
| `Esc` | 打断 Claude 当前的工作 |
| 连按两次 `Esc`（输入框为空时） | 打开回退菜单；输入框有字时则清空输入 |
| `Ctrl+C` | 打断正在进行的操作；没有操作时清空输入，再按一次退出 |
| `Ctrl+O` | 打开详细记录，查看它具体做了哪些操作 |
| `Ctrl+G` | 在文本编辑器里写长提示词 |
| `Ctrl+R` | 搜索以前输入过的内容 |
| `Ctrl+V` | 粘贴剪贴板里的图片 |
| `Ctrl+B` | 把正在运行的任务放到后台 |
| `Ctrl+T` | 显示或隐藏 Claude 的待办清单 |
| 行首输入 `!` | 直接运行一条终端命令，仅终端版有 |
| 输入 `@` | 弹出文件名补全 |
| `?`（输入框为空时） | 显示快捷键帮助面板 |

> Mac 用户注意：带 `Alt` 的快捷键需要在终端软件里把 Option 键设置为 Meta 键才生效。

**VS Code 面板里**常用的几个：

| 快捷键 | 作用 |
|---|---|
| `Cmd+Esc`（Mac）/ `Ctrl+Esc`（Windows） | 在编辑区和 Claude 输入框之间切换焦点 |
| `Option+K`（Mac）/ `Alt+K`（Windows） | 把当前选中的文件位置作为引用插入输入框 |
| `Cmd+Shift+P` / `Ctrl+Shift+P` | 命令面板，输入 `Claude Code` 可看到相关命令 |

另外，`Tab` 补全和 `!` 终端快捷方式在 VS Code 面板里不可用。

### 自定义快捷键

在终端版里输入 `/keybindings`，会创建并打开 `~/.claude/keybindings.json`，修改保存后立即生效，不用重启。一个小例子：

```json
{
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor"
      }
    }
  ]
}
```

这个文件的格式很严格，改错会导致不生效。**没有明确需求就不要改**，需要时让 Claude 帮你改，并说明要把哪个键换成什么功能。`Ctrl+C`、`Ctrl+D` 等少数按键不能重新绑定。

## 课堂练习

1. 输入 `/`，浏览菜单，找出三个你觉得最有用的命令
2. 输入 `/help` 看帮助
3. 做一个自定义命令，把你日常最常用的一段"整理格式"的提示词固化下来，用一个小文件夹验证效果
4. 试一试 `/btw`：在 Claude 做任务时问一个与任务无关的问题，看看会不会影响主对话

## 小结

- 斜杠命令是不经过 AI 琢磨的"按钮"，输入 `/` 就能看到菜单
- 常用命令按流程记：`/init`、`/plan`、`/context`、`/compact`、`/clear`、`/rewind`、`/usage`
- 自定义命令本质是技能文件，写一遍可以反复用
- 快捷键不用背，记住 `Shift+Tab`、`Esc`、双击 `Esc` 就够用
