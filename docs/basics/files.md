# 文件与表格分析

学完这页，你能把 PDF、Word、Excel 等文件交给 Claude，完成总结、提取、对比，并知道如何核对结果。

## 可以上传什么

PDF、Word、Excel / CSV、文本文件、图片（如产品图、截图）等，点输入框的附件按钮，或直接拖入对话即可。

## 五种常用用法

| 用法 | 例子 |
|---|---|
| 总结文档 | 上传产品手册，提炼核心卖点 |
| 提取信息 | 从一批合同或报价单里，提取日期、数量、条款 |
| 分析表格 | 上传销售数据，找趋势和异常 |
| 对比文件 | 上传两份报价单，逐项列差异 |
| 读图片 | 上传展会名牌或产品图，提取文字、描述内容 |

## 示范提示词

**总结文档**

```text
附件是我司【产品名称】的产品手册。
请提炼：1）适合哪类客户；2）五个核心卖点，每点一句话；3）手册中没有写但客户可能会问的三个问题。
只依据附件内容，手册里没有的信息请直接说"手册未提及"。
```

**分析表格**

```text
附件是【某季度】各区域的销售数据（虚构示例）。
请：1）按区域汇总销售额并按高低排序；2）指出环比变化最大的两个区域；3）列出看起来异常的数据行及理由。
先说明你的计算方法，再给结果，用表格输出。
```

**对比文件**

```text
附件是供应商 A 和供应商 B 的报价单。
请用表格逐项对比：品名、单价、起订量、交期、付款条件。
最后用三句话总结两家的主要差异，不要替我做选择。
```

## 让结果更可靠的做法

- **先问它读到了什么**：上传后先让它"用三句话说说这份文件的主要内容"，确认它读对了文件，再往下做。
- **指定依据**：要求"只依据附件"，并让它标出出处，例如"注明在第几页或哪个工作表"。
- **一次一个任务**：先总结，再提取，再对比，不要全挤在一句话里。
- **表格要说明结构**：告诉它每一列代表什么，有合并单元格或多个工作表时尤其重要。
- **复杂表格先整理**：多层表头、合并单元格太多时，先整理成简单的一行一条记录。

## 数据核对：必须做

Claude 做计算和统计时可能出错，或者把相近的数字看错。至少做以下检查：

1. 总数对不对：用 Excel 自己算一遍总和。
2. 抽查几行：随机挑 3–5 条，和原文件对照。
3. 追问逻辑：让它"说明你是怎么算出这个数的"。
4. 关键数字（金额、日期、数量）一律人工复核后再对外使用。

## 敏感资料先脱敏

上传前处理一下：

- 删除或替换客户姓名、电话、邮箱、地址（如换成【客户A】）。
- 去掉报价底线、成本价、合同金额等内部信息。
- 不要上传含身份证号、银行账号的文件。

具体规则见 [使用规范与数据安全](/security/)。

## 课堂练习

1. 准备一份脱敏后的表格（或让 Claude 先生成一份虚构的月度销售表）。
2. 让它汇总、排序，并找出 2 处异常。
3. 用 Excel 自己验算一遍总数，看和 Claude 的结果是否一致。
4. 记下它出错或含糊的地方，想想该怎么调整提示词。

## 小结

- 文件上传后，先确认它读对了，再分步骤提任务。
- 要求它只依据文件，并给出处。
- 计算结果必须核对，敏感信息必须先脱敏。
