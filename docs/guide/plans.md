# 账号类型怎么选

::: warning 注意
套餐名称、价格和额度会调整，请以 [Claude 官方价格页](https://www.anthropic.com/pricing) 为准。
:::

## 常见类型

| 类型 | 适合谁 | 特点 |
|---|---|---|
| 个人付费版（Pro） | 个人日常使用 | 用量满足大多数日常工作 |
| 高用量版（Max） | 重度使用者 | 更高的使用额度 |
| 团队版（Team） | 多人协作的团队 | 统一管理成员与账单、共享项目 |

## 选择建议

- 1～2 人试用：先从个人付费版开始
- 3 人以上、需要共享资料：考虑团队版
- 每天大量使用、经常提示额度不足：考虑高用量版
