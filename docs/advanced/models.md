# 模型选择与推理强度

> 内容核对日期：2026-10-18；涉及的功能以 Claude Code 当时版本为准，请以官方文档为准。

## 学完这页你能…

- 说清 Claude Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5 各自擅长什么
- 用 `/model` 切换模型，用 `/effort` 调整"想得多深"
- 知道 `opusplan`、快速模式、1M 上下文、顾问（advisor）分别解决什么问题
- 面对一项业务任务，能判断该选哪个模型

## 为什么要选模型

Claude 不是一个模型，而是一个"模型家族"。就像公司里有资深专家、骨干员工和实习生：专家想得深但慢、贵；实习生快、省，但处理复杂问题容易出错。选对模型，能让你**又快又好，还更节省用量**。

本课程统一使用模型全名，不说"最新的 Opus""那个强的"，避免大家理解不一致。

## 四个模型怎么分

| 模型 | 定位 | 适合的业务任务 | 需要的 Claude Code 版本 |
|---|---|---|---|
| Claude Fable 5.1 | 最强，处理长而难的任务；需要手动选择，不是任何套餐的默认 | 复杂研究、长流程的综合分析 | 需 v2.1.257 及以上 |
| Claude Opus 5.5 | 复杂推理；各主要套餐的默认模型 | 方案规划、深度分析、写重要文稿 | 需 v2.1.280 及以上 |
| Claude Sonnet 5.5 | 日常主力，速度和质量均衡 | 日常整理、写作、数据处理 | 需 v2.1.284 及以上 |
| Claude Haiku 5.5 | 快、省 | 简单、批量、重复的小任务 | 需 v2.1.293 及以上 |

说明：

- 上表是 2026-10-18 在 Anthropic 官方服务上的默认版本。如果你的公司通过其他云平台（如亚马逊 Bedrock、微软 Foundry）使用，对应的版本可能更旧，请向管理员确认。
- Fable 的用量在部分套餐上可能计入"额外用量（usage credits）"，第一次选择时 Claude Code 会征求你的同意。具体规则请看[官方模型配置页](https://code.claude.com/docs/en/model-config)，本教程不写价格和额度。
- 版本升级很快，升级后只需更新这张表，其他页面都会引用这里。
- 如果版本低于上表要求，在终端运行 `claude update` 升级。（终端是输入文字命令的窗口，如何打开见[安装与第一次运行](/advanced/install)。）

## 怎么切换模型

在 Claude Code 的对话框里输入下面的内容，按回车：

```text
/model
```

会弹出一个选择列表，用方向键选择。也可以直接带上名字：

```text
/model sonnet
```

常用的简称（官方叫"别名"）：

| 简称 | 含义 |
|---|---|
| `fable` | Claude Fable 5.1 |
| `opus` | Claude Opus 5.5 |
| `sonnet` | Claude Sonnet 5.5 |
| `haiku` | Claude Haiku 5.5 |
| `default` | 恢复为你账号的默认模型 |

在选择列表里，按 Enter 是"切换并保存为默认"，按 `s` 是"只对本次对话生效"。

如果想一开始就指定模型，在终端启动时加参数：

```text
claude --model sonnet
```

## 推理强度：让它"想得多深"

**推理强度**（官方叫 effort）决定 Claude 回答前"思考"多久。强度越高，想得越深，也越慢、越消耗用量。共五档：

| 档位 | 通俗理解 | 适合 |
|---|---|---|
| `low` | 快速反应 | 改个格式、简单问答 |
| `medium` | 常规思考（Opus 5.5、Sonnet 5.5、Haiku 5.5 的默认档） | 大多数日常任务 |
| `high` | 认真推敲 | 需要多步分析的任务 |
| `xhigh` | 深入研究 | 复杂分析、重要文稿 |
| `max` | 全力以赴 | 最难的问题，不常用 |

设置方法：

```text
/effort
```

弹出滑块，用左右键调节；也可以直接写 `/effort high`。`/effort auto` 表示恢复默认。

另有一个小技巧：在某一句提示词里写上 `ultrathink`，只让这一轮想得更深，下一轮自动恢复。

> 提示：`/effort ultracode` 是另一类开关（让 Claude 自己编排大批量子任务），不是推理强度的档位，属于选学内容，见[动态工作流](/advanced/optional/workflows)。

## opusplan：先规划，后执行

`opusplan` 是一个组合：**规划阶段用 Opus，动手执行阶段换成 Sonnet**。好比资深专家先出方案，骨干员工照方案去做。质量和用量之间取得折中。

```text
/model opusplan
```

配合 Plan 模式（先出方案再动手，见[日常操作](/advanced/daily-use)）使用效果最好。

## 快速模式：同一个模型，更快输出

输入 `/fast` 可以开关快速模式。要点：

- 它不是另一个模型，而是让 Claude Opus 更快地输出（官方称最高约 2.5 倍），质量不变，**费用更高**。
- 只支持 Opus 系列，不支持 Sonnet 和 Haiku；在其他模型上打开会自动切换到 Opus。
- 目前是"研究预览"功能；订阅用户需要先开通"额外用量（usage credits）"，团队和企业版还需要组织所有者先启用。
- 适合：你盯着屏幕等结果的互动场景，如现场演示、快速反复修改。不适合：放着让它慢慢跑的长任务。

## 1M 上下文：一次读很长的资料

上下文是 Claude 的"工作记忆"（见[上下文与用量管理](/advanced/context-usage)）。"1M"指约 100 万 token 的容量，大致相当于几十万字。Claude Fable 5.1、Claude Haiku 5.5 以及 Sonnet 5 及以后的版本原生支持，**不需要额外设置**。

好处是可以一次放进更多资料，如整个客户资料文件夹。但放得越多，每轮消耗越多，所以"能放"不等于"都该放"。

## 顾问（advisor）：干活的向高手请教

**顾问**让当前模型在关键时刻向另一个更强的模型请教，例如开工前确认思路、反复出错时求助、交付前检查一遍。

```text
/advisor opus
```

关闭用 `/advisor off`。要点：

- 需要 v2.1.260 及以上才能在所有界面使用 `/advisor`；目前标注为"实验性"功能。
- 只在 Anthropic 官方服务上可用，通过 Bedrock、Foundry 等云平台使用时不可用。
- 顾问的模型必须不弱于主模型。常见搭配："Claude Sonnet 5.5 干活 + Claude Opus 5.5 顾问"：日常步骤用 Sonnet，关键决策请 Opus 把关。
- 什么时候请教由 Claude 自己判断，你也可以在提示词里要求"动手前先请教顾问"。

## 什么任务用哪个模型

| 任务 | 建议 |
|---|---|
| 把 50 份产品说明批量改名、提取字段 | Claude Haiku 5.5，或 Claude Sonnet 5.5 配 `low`/`medium` |
| 日常写邮件、整理会议纪要、做汇总表 | Claude Sonnet 5.5（默认强度即可） |
| 市场分析报告、竞品对比、重要方案 | Claude Opus 5.5，`high` 或 `xhigh` |
| 先定方案，再批量执行 | `opusplan` |
| 一整个行业几十份资料的综合研究 | Claude Fable 5.1 |
| 日常用 Sonnet，但怕关键判断出错 | Sonnet 5.5 加 Opus 5.5 顾问 |
| 现场演示、需要立刻看到结果 | Opus 5.5 加 `/fast` |

经验法则：**先用够用的最小模型，不够再升级**；"贵"的模型不一定让简单任务变得更好。

## 课堂练习

1. 输入 `/model`，记录你账号当前可选的模型和默认模型。
2. 同一个任务做两遍：让 Claude 把一份资料总结成 5 条要点。第一遍用 `/model haiku`，第二遍用 `/model opus` 并设 `/effort high`。对比结果和等待时间。
3. 把对比结果填一张小表：任务、模型、强度、耗时感受、质量评价。

## 小结

- 四档模型：Claude Fable 5.1（最强）、Claude Opus 5.5（深度推理）、Claude Sonnet 5.5（日常主力）、Claude Haiku 5.5（快而省）。
- `/model` 切模型，`/effort` 调想的深度，`opusplan` 分工，`/fast` 提速，`/advisor` 请高手把关。
- 先用够用的小模型，再按需升级。
