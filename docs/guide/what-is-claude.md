# Claude 是什么

学完这页，你能用一句大白话向同事解释 Claude 是什么、怎么工作，并说出它擅长的几类工作。

## 一句话介绍

Claude 是 Anthropic 公司开发的 AI 助手。你用日常语言向它提问或布置任务，它用文字（有时还有表格、网页、文件）回答你。它擅长长文阅读、写作、分析推理和编程。

## 它背后是什么：大模型

Claude 背后是一种叫"**大语言模型**"（简称大模型）的技术。你不需要懂数学，记住一个类比就够了：

> 想象一位读过海量书籍、文章和资料的"超级实习生"。你给他一段话，他会根据读过的所有内容，判断"接下来最合理的内容是什么"，一个词一个词地接下去，最后连成完整的回答。

这就是大模型的基本原理：**根据上下文，预测并接出下一个词。** 因为读得足够多、训练得足够好，接出来的内容往往既通顺又有道理。

### 这个原理带来三个直接后果

| 后果 | 业务上的意思 |
|---|---|
| 它的回答取决于你给的上下文 | 你说得越具体、背景给得越全，结果越好；这就是"提示词"（你输入给 AI 的那段话）的作用 |
| 它追求"听起来合理" | 即使不确定也可能写得很自信，所以关键信息要核对（下一页详细讲） |
| 它没读过你们公司的内部资料 | 需要你把资料交给它，它才能基于资料回答 |

## 它能做什么

| 类型 | 业务例子 |
|---|---|
| 阅读与总结 | 把一份 60 页的行业报告压缩成一页要点；从合同里找出付款条款 |
| 写作与润色 | 写客户跟进邮件、改写产品介绍、把中文邮件译成英文 |
| 分析与推理 | 对比三家供应商的报价，指出各自风险 |
| 整理与提取 | 把一堆杂乱的会议记录整理成待办清单；从邮件里提取订单信息填进表格 |
| 编程与数据处理 | 帮你写 Excel 公式，或批量处理表格（高级篇会专门讲） |
| 头脑风暴 | 给新品想十个卖点角度，供你挑选 |

## 它不是什么

- **不是搜索引擎**：搜索引擎找到现成网页给你；Claude 是"生成"回答。在开启联网搜索时它才会查网页（基础篇讲）。
- **不是什么都知道的专家**：它的知识有截止日期，也可能出错。
- **不是替你做决定的人**：它给的是参考意见，商业决策、对外承诺、合规判断由你负责。

## Claude 有哪几个"档位"

Claude 有不同的模型，像同一家公司的不同工种：有的更强、有的更快更省。本课程统一使用全名：

| 模型 | 大致定位 |
|---|---|
| Claude Fable 5.1 | 能力最强，处理长而难的任务 |
| Claude Opus 5.5 | 擅长复杂推理 |
| Claude Sonnet 5.5 | 日常主力，速度和质量均衡 |
| Claude Haiku 5.5 | 快、省，适合简单重复的小任务 |

具体怎么选，基础篇和高级篇会讲。各套餐可用的模型不同，以官方页面为准。<!-- TODO 核实：各套餐可用模型与默认模型，随官方调整 -->

## 在哪里用 Claude

网页端、桌面应用、手机应用都可以直接对话；另有面向进阶用户的 Claude Code，可以在你的电脑上操作文件。本课程先从网页端开始。

## 课堂练习：第一次对话（5 分钟）

1. 登录 Claude，新建一个对话。
2. 复制下面的提示词，把【】换成你工作中的一个专业词，发送：

```text
我在【公司/部门】做【你的岗位】。请用不懂行的同事也能听明白的话，解释"【一个你工作中的专业词】"是什么意思，并举一个我们日常工作中可能遇到的例子。
```

3. 看看解释是否准确。如果不准，直接追问："这里和我们的实际情况不一样，我们是……"，观察它如何调整。

## 小结

- Claude 是基于大模型的 AI 助手，原理是根据上下文接出最合理的下一个词。
- 它擅长阅读、写作、分析、整理，但不了解你的内部情况，也不能替你做决定。
