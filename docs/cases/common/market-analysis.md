# 市场分析

## 分析框架

| 维度 | 要回答的问题 |
|---|---|
| 市场规模 | 市场有多大，增长趋势如何 |
| 用户需求 | 当地用户关心什么、偏好什么 |
| 渠道 | 主要销售渠道和平台 |
| 准入 | 认证、法规、关税等门槛 |
| 风险 | 汇率、政策、竞争等风险 |

## 示范提示词

```text
请从市场规模、用户需求、销售渠道、准入要求、主要风险五个维度，
分析【产品类别】在【目标国家】市场的机会。
每个维度给出要点，并列出你需要我补充或需要核实的信息。
```

::: warning 核实数据
市场规模、法规等数据可能不准确或已过时，请以官方统计和权威来源为准。
:::
