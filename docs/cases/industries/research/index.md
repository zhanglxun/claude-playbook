# 研究行业

> **预留，内容后续补充。** 本页只说明计划涵盖的方向，不是完整教程。

这里的"研究"泛指行业研究、政策研究、学术和咨询类的资料型工作：读得多、写得多、引用要准。后续补充时，同样遵循"分析框架、示范提示词、课堂练习、两种做法对照"的结构，案例使用虚构课题。

## 计划涵盖的高频场景方向

1. **文献检索与综述整理**：对一批公开文献做分类、摘要和观点对照，每条结论标注出处。
2. **资料库建设**：把大量 PDF、网页存档整理成带标签的汇总表，便于检索。
3. **访谈与会议记录整理**：把录音转写稿提炼成要点、观点矩阵和待跟进事项（受访者信息先脱敏）。
4. **数据说明与图表解读**：解读公开统计表格，指出口径差异和异常，由人复核原始数据。
5. **报告初稿与引用核对**：搭建报告框架、起草初稿，并对引用逐条核对。

## 使用前提醒

- 研究类最怕"编造引用"。所有文献、数据、引文都必须回到原文核实。
- 涉及受访者个人信息或保密协议的资料，不要上传。
- 联网研究的方法可先参考 [联网搜索与深度研究](/basics/research)。
