# AI 的能力与局限

学完这页，你能说出 Claude 容易出错的四个原因，并知道每种情况下该怎么防范。

了解局限不是为了不信任它，而是为了**用对地方、查对地方**。

## 局限一：幻觉，一本正经地编

"幻觉"指 AI 生成了看起来很合理、其实不存在或不正确的内容。比如编造一个不存在的行业报告标题、一个错误的数据来源，或写错某个国家的进口政策。

**原因**：回想一下上一页的原理，它在"接最合理的下一个词"，追求的是通顺合理，并不等于它去核对了事实。

**容易出现幻觉的内容**：
- 具体数字、日期、百分比
- 人名、公司名、引用的文献和链接
- 冷门的专业细节、最新政策和法规

**怎么防范**：
- 关键数字和结论，回到原始资料或官方来源核对
- 让它基于你提供的资料回答，并要求标明出处
- 允许它说"不知道"

```text
请只根据我上传的资料回答。每个结论后面标注出自资料的哪一部分；如果资料里没有答案，请直接说"资料中未提及"，不要推测。
```

## 局限二：知识有截止日期

Claude 的知识来自训练时的资料，有一个截止时间，之后发生的事它默认不知道。比如新出的关税政策、竞品刚发布的产品。

**怎么防范**：
- 涉及最新信息，开启联网搜索（基础篇讲），或自己把最新资料贴给它
- 在提示词里告诉它今天的日期和你关心的时间范围

## 局限三：上下文窗口，"工作记忆"有限

"上下文窗口"是它在一次对话里能同时"看到"的内容量上限，可以类比为桌面大小：桌上放得下的资料它才能同时参考。

- 对话很长、资料很多时，早先的内容可能被忽略或遗漏
- 一次塞入过多资料，也会降低它对细节的关注

**怎么防范**：
- 一个对话只做一件事，换主题就新建对话
- 长资料分段处理，或先让它出摘要再往下做
- 重要要求隔一段就重申一次

## 局限四：每次对话相互独立

新建一个对话，它不会自动记得上一个对话聊过什么（部分产品功能如记忆、Projects 可以保存背景，基础篇会讲）。

**怎么防范**：
- 把需要长期沿用的背景、格式要求保存下来，每次贴给它
- 后面学习的 Projects 就是解决这个问题的

## 一张表看懂

| 局限 | 表现 | 对策 |
|---|---|---|
| 幻觉 | 编造数据、来源 | 核对原始来源；要求依据资料作答 |
| 知识截止 | 不知道最新信息 | 联网搜索或自己提供资料 |
| 上下文有限 | 长对话中遗漏细节 | 分段、一事一议、重申要点 |
| 对话独立 | 不记得上次内容 | 保存背景，用 Projects |

## 因此：必须核对

建立一个习惯：**越重要、越具体、越是对外发出去的内容，核对越要认真。**

| 风险等级 | 例子 | 做法 |
|---|---|---|
| 低 | 内部头脑风暴、润色语句 | 快速浏览 |
| 中 | 内部分析报告初稿 | 核对关键数据与结论 |
| 高 | 合同条款、报价、对客户的承诺、法规解读 | 逐条核对原始来源，必要时请专业人士确认 |

## 课堂练习：抓一个"幻觉"

1. 向 Claude 提一个你熟悉领域里的具体问题，例如：

```text
请列出【你所在行业】近两年的三份重要行业报告，包括发布机构、标题和主要结论。
```

2. 用你的专业知识逐条核对，看哪些是真的、哪些存疑。
3. 再追问："你确定这些来源真实存在吗？请说明哪些是你不确定的。"观察它的反应。

## 小结

- 四个局限：幻觉、知识截止、上下文有限、对话独立。
- 对策共同点：给它资料、让它标明依据、自己核对关键信息。
