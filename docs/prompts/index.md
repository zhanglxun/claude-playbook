# 提示词模板库

复制模板后，把【】中的内容替换成你自己的信息即可使用。模板里的公司、产品均为虚构示例。

> 用之前先记住三条：给足背景（谁、为什么）；说清格式（表格、要点、字数）；让 Claude 在信息不足时先提问。更多写法见 [提示词写法](/basics/prompting)。

## 通用模板

万能结构：角色、背景、任务、要求、兜底。

```text
你是【角色，例如：有 10 年经验的采购经理】。
背景：【公司/产品/目标，例如：我们是一家做家用收纳的小型制造企业】。
任务：【具体要做什么】。
要求：【格式、字数、语气，例如：用 5 条要点，每条不超过 30 字，语气专业简洁】。
如果信息不足，请先向我提问，不要自己编造。
```

润色改写：

```text
请把下面这段文字改写得更【简洁/正式/亲切】，保留原意和所有数字，不要增加新信息。
读者是【读者身份】，用途是【用途】。
请给我 2 个版本，并用一句话说明两者区别。

原文：
【粘贴原文】
```

先问后做（适合不知道怎么描述需求时）：

```text
我想完成【目标】，但不确定该提供哪些信息。
请你一次问我不超过 5 个最关键的问题，我回答后你再动手。
```

## 资料总结

```text
请阅读我上传的【文件名/类型，例如：行业报告 PDF】，完成以下事项：
1. 用 3 句话概括全文；
2. 列出 5 个最重要的结论，每条注明出处页码；
3. 列出文中出现的关键数据（表格：指标 | 数值 | 页码）；
4. 指出文中没有回答、但我可能关心的问题。
只使用文件中的内容；文件里没有的信息，请写"文中未提及"。
```

多份资料对比：

```text
我上传了【数量】份资料。请先分别用 2 句话概括每份，
再用表格对比它们在【对比维度，例如：结论、数据口径、时间范围】上的异同，
最后指出互相矛盾的地方。
```

## 表格分析

```text
我上传了一份 Excel：【表格内容简述，例如：2025 年各区域订单明细】。
请先告诉我你看到了哪些列、多少行，以及有没有缺失值或异常值，等我确认后再继续。
确认后请完成：
1. 按【维度，例如：区域、月份】汇总【指标，例如：销售额】；
2. 找出同比/环比变化最大的 3 项，并推测可能原因（标明是推测）；
3. 给出一段不超过 200 字的结论，写给不懂技术的管理层。
计算过程请写出来，方便我核对。
```

::: tip 数据核对
让 Claude 报告数字时，抽查 2–3 个数字对照原表。大表格建议要求它"写出计算方法"。
:::

## 产品调研

完整框架和课堂练习见 [产品调研分析](/cases/common/product-research)。

```text
你是一名产品调研分析师。请调研【产品/品类，例如：便携式榨汁杯】。
目的：【目的，例如：判断是否值得在 2026 年新增这条产品线】。
请按以下结构输出：
1. 产品定义与主要使用场景；
2. 目标用户画像（2–3 类）及核心需求；
3. 主流产品的价格带、卖点、常见差评（来自公开信息，注明来源）；
4. 机会点与风险；
5. 还需要补充调查的问题清单。
请区分"有来源的事实"和"你的判断"。联网搜索时给出网址。
```

## 市场分析

完整框架见 [市场分析](/cases/common/market-analysis)。

```text
请对【市场/地区】的【产品品类】做一份市场分析，读者是【读者，例如：公司管理层】。
包括：市场规模与增速、主要参与者、渠道结构、政策与准入、趋势。
要求：
- 每个数据标明来源和年份，查不到就写"未查到"，不要估算后当作事实；
- 最后给出 3 条行动建议，并说明各自的前提假设。
输出为：先给一页摘要，再给详细分析。
```

## 竞品对比

完整框架见 [竞品对比](/cases/common/competitor)。

```text
请对比【我方产品】与【竞品 A】【竞品 B】。
对比维度：【功能/价格定位/目标客户/渠道/口碑，可增删】。
请用表格输出，最后一列写"我方相对优劣"。
然后回答：
1. 我方最可能赢的客户是哪类，为什么？
2. 竞品最大的威胁是什么？
3. 我们可以在【一个季度】内做的 3 个动作。
信息来源仅限我提供的资料和公开网页，来源请标出。
```

## 外贸邮件

更多邮件场景见 [贸易行业](/cases/industries/trade/)。

开发信：

```text
请写一封英文开发信。
我方：【公司简介，一句话】，产品：【产品】，主要卖点：【2–3 点】。
收件人：【职位/公司类型】，所在国家：【国家】。
要求：不超过 150 词；开头点出对方可能关心的问题；结尾只提一个明确的下一步（例如回复索取样品目录）；
语气礼貌、不夸张；不要使用"best in the world"这类绝对化表述。
请给出主题行 3 个备选。
```

回复询盘：

```text
这是客户的询盘邮件：
【粘贴邮件】
我方的可报信息：【产品规格、起订量、交期，不含底价】。
请写回信：先感谢并确认需求，逐条回答客户的问题，
对我方信息中没有的内容，用"我们将与生产部门确认后答复"之类的措辞，不要自行承诺。
另外用中文列出 3 点：这封邮件里客户真正关心什么、我回信时要注意什么。
```

跟进催复：

```text
客户【客户称呼】在【日期】收到我们的报价后一直没有回复。
请写一封简短的英文跟进邮件（不超过 80 词），语气友好、不施压，
提供一个低门槛的回复方式（例如：只需回复"有兴趣/暂不需要"）。
```

## 会议纪要

```text
下面是会议记录/录音转写文字：
【粘贴内容】
请整理成会议纪要：
1. 会议主题、时间、参会人（原文没有就留空）；
2. 已达成的决定（逐条）；
3. 待办事项表：事项 | 负责人 | 截止时间 | 备注；
4. 未解决的问题或分歧。
只依据原文，不要补充没说过的内容；负责人或时间不明确时标"待确认"。
控制在一页以内。
```

## 周报

```text
请根据我下面的工作记录写本周周报，读者是【直属领导】。
工作记录：
【粘贴要点或聊天记录】
格式：
- 本周完成（按重要性排序，每条一句话，带结果或数字）；
- 进行中（注明进度和预计完成时间）；
- 问题与需要的支持；
- 下周计划。
语气简洁，不要夸大。没有数据支撑的内容不要加形容词。
```

想让 Claude 每周自动沿用同一格式，可以把模板放进 Projects，参见 [Projects 项目功能](/basics/projects)；在 Claude Code 中做则见 [Claude Code 模板](/prompts/claude-code)。

## 追问与修改

得到初稿后，常用的追问：

```text
- 请把第【几】点展开成 100 字的说明，并补充一个例子。
- 请检查上面内容里有没有前后矛盾或没有依据的地方，并逐条列出。
- 请站在【对方角色，例如：挑剔的客户】的角度，指出这份内容最可能被质疑的 3 点。
- 请用更口语的方式重写，面向完全不懂行业的读者。
```
