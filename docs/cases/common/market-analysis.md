# 市场分析

市场分析回答的是：**这个市场值不值得进入、怎么进入？** Claude 擅长把零散信息整理成结构，但它给出的具体数字可能不准确、已过时，所以本页的核心思路是：**让 Claude 搭框架、整理资料，数据由人到来源核对。**

> 案例为虚构：某家居出海品牌考虑进入"某国"的折叠收纳家具市场（示意）。本页不提供任何真实市场数据。

## 分析框架

| 维度 | 要回答的问题 | 资料从哪里来（公开渠道） |
|---|---|---|
| 市场规模 | 市场有多大，趋势如何 | 官方统计机构、行业协会报告 |
| 用户需求 | 当地用户关心什么、偏好什么 | 电商评论、社交媒体、调研报告 |
| 渠道 | 主要销售渠道和平台 | 平台公开页面、行业文章 |
| 准入 | 认证、法规、关税等门槛 | 政府官网、海关和标准机构公告 |
| 竞争 | 主要对手与价格带 | 竞品官网和电商页面（见[竞品对比](/cases/common/competitor)） |
| 风险 | 汇率、政策、物流等 | 官方公告、权威新闻 |

## 示范提示词

### 第一步：搭框架，不要数字

```text
我们是一家做【产品类别】的品牌，考虑进入【目标国家】市场。
请从市场规模、用户需求、销售渠道、准入要求、竞争格局、主要风险六个维度，
列出我们需要调研的问题清单。

要求：
- 每个维度给出 3 到 5 个具体问题
- 每个问题注明建议去哪类公开渠道查找（如官方统计网站、行业协会、海关公告）
- 暂时不要给出具体数字
- 用表格输出：维度 | 问题 | 建议资料来源
```

### 第二步：基于你提供的资料分析

把你找到的公开报告、文章上传后：

```text
请阅读我上传的【N】份资料，按市场规模、用户需求、渠道、准入、风险五个维度整理要点。

要求：
- 每条结论后用括号注明出处（文件名和页码或章节）
- 资料中相互矛盾的数据，请并列写出并指出差异
- 资料没有覆盖的维度，写"资料不足"，并建议补充什么资料
- 所有数字、法规名称单独列在最后一张表里，列：内容 | 出处 | 是否需要人工核对
```

### 第三步：形成建议

```text
基于以上分析，请给出：
1. 进入该市场的 3 个主要机会
2. 3 个最大的不确定因素
3. 下一步 30 天内建议做的 5 件调研动作
用清晰的小标题输出，篇幅控制在一页以内。
```

::: warning 核实数据
市场规模、法规、关税、认证要求等事实性内容，Claude 可能出错或已过时。请让它标注来源，并由人到官方统计和权威来源核对后再用于决策或对外材料。
:::

## 课堂练习

1. 选一个你关心的目标市场，用第一步提示词生成调研问题清单。
2. 找 2 份公开资料上传，用第二步提示词整理，检查"需要人工核对"表。
3. 挑其中 3 条数字，亲自到来源核对，记录 Claude 有没有引用错误。

## 注意事项

- 不要问"某国市场规模是多少"然后直接使用答案，应改为"根据我提供的资料……"。
- 开启联网搜索时，仍要点开来源核对，参见 [联网搜索与深度研究](/basics/research)。
- 调研只使用公开渠道的资料，不涉及绕过任何平台或地区规则的做法。

## 两种做法对照

### 网页版做法

- 把找到的 2 到 5 份公开资料上传，用第二步提示词整理。
- 需要最新信息时开启联网搜索，并要求列出来源链接。
- 长期跟踪某个市场，用 [Projects](/basics/projects) 保存历次资料和结论。

```text
请阅读我上传的资料，整理【目标国家】市场的渠道和准入要求，每条结论注明出处，数字类内容单独列表并标注"需人工核对"。
```

### Claude Code 做法

- 把收集来的报告、网页保存的 PDF、整理好的表格放进同一个文件夹，如 `市场资料/某国/`。
- 让它读取全部文件，统一提炼并汇总成表，再出一份完整报告。
- 把"必须标注出处、数字单独核对"写进 `CLAUDE.md`，换国家时复用；固定流程做成 [Skills](/advanced/skills)。

```text
请读取 市场资料/某国/ 文件夹下的所有文件。
1. 按市场规模、用户需求、渠道、准入、风险五个维度提取要点，保存为 要点汇总.xlsx（列：维度、要点、出处文件、页码）。
2. 把所有数字和法规名称另存一个工作表"待核对清单"。
3. 基于汇总写一份不超过 3 页的市场分析报告，保存为 某国市场分析报告.docx。
每条结论必须能对应到出处；资料不足的维度明确写出。
```

了解更多：[Claude Code 是什么](/advanced/what-is-claude-code)。

## 小结

市场分析的正确姿势：Claude 负责列问题、读资料、做结构，人负责找来源、核数据、做判断。
