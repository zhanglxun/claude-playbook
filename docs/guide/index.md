# 课程介绍

学完这页，你会知道这门课讲什么、适合怎么学，以及从哪一页开始。

> 本教程为独立编写的培训材料，**不是 Anthropic 官方文档**。产品功能以官方说明为准。

## 这门课适合谁

- 刚开通 Claude、希望快速上手的企业员工
- 需要做产品调研、市场分析、外贸沟通的业务人员
- 完全不懂技术也没关系：术语第一次出现都会用大白话解释

## 课程怎么编排

先"认识"，再"会用"，最后"用好"：

1. **入门篇**：Claude 是什么、它擅长和不擅长什么、该用什么心态与它合作、账号怎么选怎么保护。
2. **基础篇**：在网页端和桌面端熟练使用提示词、文件分析、Projects 等核心功能。
3. **高级篇**：Claude Code，让 AI 在你的电脑上读文件、改文件、跑任务。
4. **场景与行业篇**：把前面学到的用在具体的业务场景里。

命令、Skills、MCP、Agent 这几个概念会在三个篇章里分层出现：入门篇只"认识"（一句话），基础篇"会用"，高级篇"用好"。所以第一次看不懂完整用法完全正常。

## 学习路线

| 章节 | 内容 | 自学时长（估） |
|---|---|---|
| 入门篇 | Claude 是什么、能力与局限、协作心态、账号类型、安全设置、概念地图 | 约 2 小时 |
| 基础篇 | 提示词、文件分析、Projects、Artifacts、联网研究、连接应用 | 约 3.5 小时 |
| 高级篇 | Claude Code 业务应用（核心课必学，选学专题按需） | 核心约 6 小时 |
| 场景与行业篇 | 通用场景 + 按所在行业选学 | 按需 |
| 工具与规范 | 提示词模板、使用规范、常见问题、术语表 | 随用随查 |

## 学完你能做到

1. 理解 Claude 为什么这样工作，知道什么时候该信、什么时候该核对
2. 写出结构清晰、结果稳定的提示词
3. 让 Claude 读懂你的产品资料和表格数据
4. 用固定的分析框架完成一份产品调研或市场分析初稿
5. 知道 Claude Code 能做什么，并把它用到自己的业务里

## 怎么学效果最好

- **边学边做**：每页的小任务都用你自己的真实工作内容来练，比看十遍都有效。
- **不用死记**：提示词模板可以反复回来取用。
- **有疑问先试再问**：Claude 本身就是最好的陪练，可以让它给你解释看不懂的词。

准备好了就从 [Claude 是什么](/guide/what-is-claude) 开始。
