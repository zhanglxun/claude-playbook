# 提示词写法

学完这页，你能把一句含糊的需求，改写成 Claude 一次就能做对的清晰指令，并学会通过追问把结果改到满意。

**提示词**就是你对 Claude 说的话。它不是什么咒语，本质上和你给新同事布置工作一样：说清楚谁来做、背景是什么、做什么、做成什么样。

## 好提示词的五个要素

| 要素 | 说明 | 例子 |
|---|---|---|
| 角色 | 让 Claude 以什么身份回答 | 你是一名有 10 年经验的外贸业务经理 |
| 背景 | 提供必要的上下文 | 我们是做家居用品出口的，主要市场是欧洲 |
| 任务 | 明确要做什么 | 分析这款产品在德国市场的三个主要卖点 |
| 格式 | 规定输出的样子 | 用表格列出，每条不超过 30 字 |
| 示例 | 给一个想要的样子 | 参考这种写法：「防水耐用，适合北欧多雨气候」 |

不是每次都要五项齐全。简单问题一句话就够，复杂、重要的任务才需要写全。

## 差的写法 vs 好的写法

**例 1：写产品介绍**

差的写法：

```text
帮我写个产品介绍
```

问题：不知道什么产品、给谁看、多长、什么风格，Claude 只能猜。

好的写法：

```text
你是一名家居用品的资深文案。
背景：我们是一家出口欧洲的家居公司，要向德国经销商介绍一款可折叠收纳凳【产品名称与主要参数】。
任务：写一段产品介绍，突出耐用、省空间、易清洁三点。
格式：150 字以内，语气专业克制，不要夸张的形容词。最后单独列出 3 个关键卖点。
```

**例 2：整理会议内容**

差的写法：

```text
总结一下这次会议
```

好的写法：

```text
下面是一次产品周会的记录【粘贴记录】。
请提炼：1）已做出的决定；2）待办事项，含负责人和截止日期；3）仍有争议的问题。
用三个小标题输出，每项用一句话，不要复述讨论过程。
如果记录里没有写明负责人或日期，请标注"未明确"，不要自己猜。
```

## 实用技巧

- **给例子**：给一个你想要的样例，效果远好于一大段描述。
- **分步骤**：复杂任务拆成几步，一步一步来，每步检查。
- **让它先问**：不确定时加一句"如信息不足，请先向我提问，再动手"。
- **说清不要什么**：例如"不要使用行业黑话""不要编造数据"。
- **限定范围**：告诉它只能依据你提供的资料，资料里没有就说没有。

## 追问和迭代

第一次结果不满意很正常。不必重写整段，直接指出要改哪里：

```text
整体可以，但请调整：
1. 第二段太长，压缩到两句话；
2. 语气再正式一些；
3. 增加一个对比数据的小表格。
```

也可以让 Claude 自己改进你的提示词：

```text
我想让你帮我做【任务】。请先问我 5 个能让结果更好的问题，我回答后你再开始。
```

## 常见反例

| 反例 | 问题 | 改进 |
|---|---|---|
| 一句话说完复杂需求 | 信息不足，只能猜 | 补充背景、对象、格式 |
| 一次塞十个任务 | 每个都做不深 | 拆成多轮，逐个完成 |
| 只说"写得好一点" | 标准不明 | 指明"更简短""更口语" |
| 完全信任第一版 | 可能有错误 | 核对关键事实后再用 |

## 两条红线

1. **敏感资料先脱敏。** 客户名称、联系方式、报价底线、合同金额等，先删掉或替换成【客户A】再粘贴。详见 [使用规范与数据安全](/security/)。
2. **重要结论必须人工核对。** Claude 可能一本正经地给出错误信息（俗称"幻觉"）。数据、日期、法规、引用来源，都要自己再确认。

## 课堂练习

用五要素改写这句提示词：「帮我写个产品介绍」。要求：换成你自己公司的真实产品（用虚构名称代替也可以），再追问修改两次，对比第一版和最终版。

## 小结

- 好提示词 = 角色 + 背景 + 任务 + 格式 + 示例。
- 先写清楚，再追问，不满意就指出具体问题。
- 脱敏在前，核对在后。
