# 竞品对比

竞品对比的目的不是列出一张漂亮的表，而是**找到我们可以切入的差异化机会**。Claude 适合做的是：把分散在各处的公开资料整理成同一把尺子下的对比，并归纳用户评论里的主题。

> 案例为虚构：某家居出海品牌的"静音折叠收纳凳"对比三个示意竞品 A、B、C（名称与数据均为示意）。

## 分析框架

| 维度 | 看什么 |
|---|---|
| 价格带 | 定价区间、是否常做促销（记录页面显示信息及日期） |
| 核心功能 | 主要功能、规格、材质 |
| 目标客群 | 他们主要瞄准谁 |
| 渠道 | 在哪些平台、官网销售 |
| 口碑 | 好评主题、差评主题 |
| 优劣势 | 相对我们的强项与短板 |

资料只用公开渠道：官网、电商页面、公开的用户评论、公开的评测文章。价格和评分会变化，记录时写明采集日期。

## 示范提示词

### 一：多竞品对比表

把各竞品的官网介绍、页面截图或整理的文字上传后：

```text
我会提供【3】个竞品的公开资料，分别是【竞品A】【竞品B】【竞品C】，以及我们产品【我方产品】的资料。
请做一张对比表，列为各产品，行包括：价格区间、核心功能、目标客群、销售渠道、主要优势、主要短板。

要求：
- 只依据我提供的资料，没有的信息写"资料未提及"，不要推测
- 价格请注明资料中的日期或来源
- 表后总结我们产品可以切入的差异化机会（3 条），每条说明依据
- 最后列出你认为需要我补充的资料
```

### 二：用户评论归纳

把评论整理成文件（如 Excel 或文本，一行一条）上传：

```text
这是【竞品名称】的公开用户评论，共【N】条。请：
1. 归纳好评的前 5 个主题，每个主题给出评论条数的大致比例和 2 条原文例子
2. 归纳差评的前 5 个主题，同样格式
3. 找出竞品的未被满足的需求：用户希望有、但产品没做到的
4. 针对我们产品，给出 3 条可用于卖点或改进的建议
评论数量较少时请说明结论的可靠性有限。
```

## 课堂练习

1. 选 3 个真实公开可查的同类产品，整理资料后用提示词一做对比表。
2. 找一个竞品的 30 条以上公开评论，用提示词二归纳，检查主题比例是否合理。
3. 讨论：哪一条"差异化机会"你们最有把握做到？

## 注意事项

- **别让 Claude 凭印象评价竞品**：它对具体品牌的信息可能陈旧或不准，务必限定"只依据我提供的资料"。
- **评论要有足够数量**：几条评论不足以代表整体，结论仅作线索。
- **不使用不当手段获取资料**：只用公开可见的内容，遵守平台规则，不涉及绕过限制的做法。
- 对外引用竞品信息前，人工复核。

## 两种做法对照

### 网页版做法

- 把 3 到 4 个竞品的资料和评论文件一起上传，用提示词一、二逐步完成。
- 竞品名单固定时，建立 [Projects](/basics/projects)，把对比框架写进项目指令，每季度更新资料。
- 适合：竞品不多、资料已整理好。

```text
请对比我上传的三家竞品资料和我方产品资料，输出对比表（价格、功能、客群、渠道、优势、短板），并给出 3 条差异化机会，资料未提及的写"资料未提及"。
```

### Claude Code 做法

- 每个竞品一个子文件夹，里面放官网介绍、评论文件、截图整理稿。
- 让它读取全部子文件夹，生成统一对比表、每个竞品的评论归纳，以及总报告。
- 在 `CLAUDE.md` 约定"只用资料、写明出处、标注采集日期"；每季度更新时直接重跑，也可做成 [Skills](/advanced/skills)。

```text
请读取 竞品资料/ 下的所有子文件夹（每个子文件夹是一个竞品，含介绍文档和 评论.xlsx）。
1. 汇总为 竞品对比表.xlsx：每个竞品一行，列为价格区间、核心功能、目标客群、渠道、优势、短板。
2. 对每个竞品的评论归纳好评和差评各 5 个主题，保存到 报告/评论归纳_竞品名.md。
3. 写一份总结报告 竞品对比报告.docx，包含 3 条差异化机会。
只依据文件内容，资料缺失处写"资料未提及"。
```

了解更多：[Claude Code 是什么](/advanced/what-is-claude-code)、[Skills](/advanced/skills)。

## 小结

竞品对比 = 统一维度 + 只依据资料 + 归纳评论 + 落到差异化机会。表格只是工具，结论才是产出。
