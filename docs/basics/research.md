# 联网搜索与深度研究

学完这页，你能判断什么时候开联网搜索、什么时候用研究功能，并学会提出研究类任务和核实来源。

## 为什么要联网

Claude 的知识来自训练资料，有截止日期，对最新的新闻、价格、政策和公司动态并不知道。联网搜索让它在回答前先去网上查，再结合结果作答。

打个比方：不联网像是闭卷考试，联网像是开卷考试，可以翻资料，但资料本身的质量你仍然要把关。

## 两种功能的区别

| 功能 | 做法 | 适合 | 耗时 |
|---|---|---|---|
| 联网搜索 | 查几次网页，直接回答 | 简单、明确、需要最新信息的问题，例如某事件的最新进展 | 很快 |
| 研究（深度研究） | 自己拆分问题，多轮搜索和阅读，最后给出带引用的长报告 | 需要综合很多来源的大问题，例如竞品对比、行业梳理 | 通常需要几分钟 |

据官方说明，研究类任务一般包含多次查询，耗时在一到几分钟，并生成带引用的较长报告；也可以结合你已连接的应用资料。具体套餐可用性和开启方式以官方帮助中心为准。

## 什么时候开联网

| 情况 | 建议 |
|---|---|
| 问最新新闻、政策、汇率、展会日期 | 开联网 |
| 查某家公司或产品的公开信息 | 开联网 |
| 根据你上传的资料做总结、改写 | 不必开，只依据文件即可 |
| 写作、翻译、头脑风暴 | 通常不必开 |
| 重要事实核对 | 开，并自己点开来源复查 |

## 如何提出研究类任务

好的研究提示词要说明：研究什么、为什么、范围、输出格式、来源要求。

```text
请研究【产品类别】在【目标市场】的当前市场情况，用于我司决定是否进入该市场。
范围：近两年的信息，优先官方统计、行业协会报告、主流媒体。
请回答：1）市场规模和趋势；2）主要竞争者；3）典型渠道；4）潜在风险。
输出：先给一页摘要，再给分节详细内容。每个关键数据后注明来源链接。
资料不足或来源之间冲突时，请明确指出，不要硬编。
```

技巧：
- **先限定范围**：时间、地区、行业，越具体越好。
- **要求注明来源**：每个重要数据附链接。
- **允许它说不知道**：避免为了凑答案而编造。
- **先小后大**：大问题先让它出研究计划，你确认后再开始。

## 来源核实：必做的三步

联网不等于正确，网页本身可能有错、过时或带有立场。

1. **点开来源**：重要数据至少点开一两个原始链接，确认文中真有这句话。
2. **看来源质量**：优先官方机构、行业协会、正规媒体；对匿名博客、营销文章保持警惕。
3. **交叉验证**：关键数字用第二个来源再确认，数字对不上就追问。

另外要注意：涉及价格、法规、合规的结论，最终要由人工确认，不能直接当作决策依据。

## 课堂练习

选一个虚构场景：我司（虚构公司）想了解【某产品】在【某国家】的市场概况。

1. 先用普通问法问一遍。
2. 再开联网或研究功能，用上面的结构化提示词问一遍。
3. 对比两次的差别，并点开三个来源，检查是否真的支持文中结论。
4. 记录你发现的不准确之处。

## 小结

- 需要最新信息时开联网；大问题用研究功能，最后一定要核实来源。
- 提示词写清范围、问题、格式和来源要求。
- 联网结果也可能出错，重要结论必须人工复核。
