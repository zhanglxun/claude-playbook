# 高级篇导览

> 内容核对日期：2026-10-18；涉及的功能以 Claude Code 当时版本为准，请以官方文档为准。

## 学完这页你能…

- 说清楚高级篇学什么、不学什么
- 知道核心课和选学专题怎么划分，按自己的情况选学习路线
- 提前准备好开始学习需要的条件

## 这一篇讲什么

前两篇你用的是 Claude 的网页端或桌面端：把资料上传上去，在对话框里一问一答，结果再自己复制出来。这种方式很方便，但有一个限制：Claude 只能看到你"递过去"的东西。

**Claude Code** 换了一种工作方式：它直接在你的电脑上工作。你指定一个文件夹，它就能读里面的全部文件、新建文件、修改文件、整理成表格，必要时还能运行工具完成任务。你不需要自己搬运资料，也不需要自己把结果一份份保存。

所以这一篇的定位是：

> **不讲编程，讲"让 AI 在你的电脑上读文件、改文件、跑任务"。**

学完之后，你可以把它当作一个坐在你电脑前的助理：给它一个资料文件夹和一个目标，它去读、去整理、去写，你来检查和拍板。

::: tip 术语提示
本篇会出现一些新词，如"终端""斜杠命令""权限模式""上下文"。每个词第一次出现都会用大白话解释，不需要任何编程基础。
:::

## 核心课与选学专题

高级篇分两部分：

| 部分 | 内容 | 怎么学 |
|---|---|---|
| **核心课（3.1–3.12）** | 从认识、安装、日常操作，到权限、记忆、模型、技能、外部连接、子代理、数据沉淀 | 必学，现场讲授以这部分为主 |
| **选学专题（3.13 起）** | Hooks、动态工作流、定时任务、多会话、远程使用、浏览器操作、插件、企业管理等 | 按需学习，可以跳过或自学 |

核心课的前七页是"基本功"，学完就能独立完成日常工作：

1. [3.1 Claude Code 是什么](/advanced/what-is-claude-code)：它和网页版有什么不同，能用在哪些业务上
2. [3.2 安装与第一次运行](/advanced/install)：装好工具，跑通第一个任务
3. [3.3 日常操作](/advanced/daily-use)：对话、检查修改、撤回、先规划再动手
4. [3.4 命令与快捷操作](/advanced/commands)：斜杠命令和快捷键
5. [3.5 权限与安全](/advanced/permissions)：它能做什么、不能做什么，如何保护敏感文件
6. [3.6 记忆与规则：CLAUDE.md](/advanced/claude-md)：让它记住你的业务背景
7. [3.7 上下文与用量管理](/advanced/context-usage)：对话太长怎么办，怎么节省用量

之后的 3.8 起再逐步进入模型选择、Skills、MCP、子代理等"用好"层面的内容。

## 学习路线建议

| 你的情况 | 建议 |
|---|---|
| 第一次接触 Claude Code | 按顺序学 3.1 → 3.7，每页做完动手任务再往下 |
| 已经用过一段时间 | 先读 3.5（权限）和 3.6（CLAUDE.md），再进入 3.8 以后 |
| 只想了解能做什么 | 读 3.1，再看 [场景与行业篇](/cases/) 里的案例 |
| 有周期性、批量性工作 | 学完核心课后，选学"目标与定时任务""动态工作流" |

## 开始前的准备

- **已完成入门篇和基础篇**：至少会写清楚需求、会检查 AI 的输出。
- **一个可用的账号**：Claude Code 需要付费订阅或 Claude Console 账号，具体以 Anthropic 官方说明为准，不要用来源不明的"代充""共享"账号。账号类型见 [账号类型怎么选](/guide/plans)。
- **一台自己的电脑**：macOS 或 Windows 均可，能安装软件。
- **一个练习用的文件夹**：里面放几份可以公开的资料（比如虚构公司的调研文档、表格），**不要用含客户机密的真实文件练手**。数据安全规则见 [使用规范与数据安全](/security/)。
- **稳定的网络环境**：按所在地区允许的方式正常使用服务。

## 课堂练习

在电脑上新建一个文件夹，命名为"练习-调研资料"，放入 3–5 份无敏感信息的文档或表格。后面每一页的动手任务都会用到它。

## 小结

高级篇的核心是：让 Claude 从"回答问题的对话框"变成"在你电脑上干活的助理"。你的工作也随之改变：从"搬运和整理"变成"交代任务、检查结果、把关风险"。
