# 把会话结果发布为 Artifacts

> 内容核对日期：2026-10-18；选学内容。部分功能为研究预览/公测，且按套餐和版本开放，请以官方文档为准。

**适合谁**：需要做汇报页、数据看板、方案对比页，或者想"发个链接给同事"而不是把一大段文字贴进聊天的人。

**学完能**：让 Claude 把会话成果发布成一个可分享、可持续更新的网页；知道怎么控制谁能看；知道如何让页面实时读取你连接的应用数据；知道哪些套餐和账号条件下才能用。

## 什么是 Artifact

Artifact（可译为"成果页"）是 Claude Code 从会话里发布到 claude.ai 上的一个**实时网页**。它先是只有你自己能看的私有链接，会话继续时，页面会**原地更新**，打开着的人能直接看到新版本。

什么时候用：当"终端里的文字"不够好看、不够好用的时候。

- 把一份调研结论做成带图表、带对比表的汇报页
- 把几个方案并排放在一页，每个配一行利弊
- 一个长任务边做边更新的进度清单，同事点链接就能跟进
- 一个"状态看板"，每次打开都拉取最新数据

它**不是**什么：它是一个独立的静态页面，没有后台服务，不能当成有登录、有多个页面的内部系统。需要真正的内部工具，请另行部署。

## 使用条件（先确认再动手）

| 条件 | 要求 |
|---|---|
| 套餐 | Pro、Max、Team、Enterprise。Team 和 Enterprise 默认开启，但管理员（Owner）可以整体关闭 |
| 登录方式 | 必须用 `/login` 登录 claude.ai 账号。用 API 密钥、网关令牌、云平台凭证的会话不能发布 |
| 模型来源 | 仅 Anthropic 官方接口。Amazon Bedrock、Google Cloud 的 Agent Platform、Microsoft Foundry 不可用 |
| 组织策略 | 开启了客户自管加密密钥（CMEK）、HIPAA 或零数据保留（ZDR）的组织不可用 |
| 使用位置 | Claude Code 命令行，或 Claude 桌面应用（需 1.13576.0 及以上版本） |
| 无界面运行 | 用 `claude -p`、Agent SDK 时默认关闭 |

背景：Artifacts 在 2026 年 6 月以公测形式先面向 Team 和 Enterprise 推出，目前官方文档已列出 Pro、Max 也可使用。具体范围以官方文档为准。

## 怎么创建和更新

直接用大白话要求：

```text
帮我做一个 artifact：把【上季度三条产品线的销量对比】做成一页汇报，
包含一个柱状图、一张对比表和三条结论。
```

Claude 会写出页面并发布，终端里打印链接，浏览器自动打开。之后：

- 想改内容：继续对话，如"在图表下面加一块按地区拆分的表格，然后重新发布"，它会更新到**同一个链接**。
- 每次发布都会成为一个**版本**，在页面右上角的 **Share** 里可以选择让查看者看到哪个版本。
- 想在新会话里继续更新旧页面：把链接发给 Claude，或用 `/artifacts`（需 2.1.208 及以上）选中它。不给链接的话，新会话会新建一个页面。
- 按 `Ctrl+]` 可以重新打开本次会话最近的一个页面。

## 怎么分享

新页面默认**只有你自己能看**。要分享，打开页面，点页眉的 **Share**：

- **组织内分享**（Team、Enterprise）：授权给组织里的指定同事，或全员。对方需要登录 claude.ai。还可以把某人设为"编辑者"，让他也能让 Claude 更新这个页面。
- **公开链接**：任何人都能打开，不用登录。Team 和 Enterprise 里默认关闭，需要 Owner 在管理后台开启"外部分享"。
- 页面上还可以收评论；被授权的编辑者可以把评论"发给 Claude"，让它按意见修改。需 2.1.221 及以上。

分享前请养成两个习惯：

1. 检查页面里有没有不该外传的数据（客户名称、报价、内部账号）。
2. 公开链接等于"知道链接的人都能看"，涉及业务数据时优先用组织内分享。

## 让页面调用你连接的 MCP 数据

页面可以在**每次被打开时**，通过 MCP 连接器去拉取最新数据，而不是只显示做页面那一刻的快照。例如：

```text
做一个 artifact 看板：展示【我们团队本周的待办事项】，
通过我的【日历/项目管理】连接器在页面打开时实时读取，
并在每个实时区块里加一句提示：如果没连接【对应连接器】，请先去连接。
```

要点（需 Claude Code 2.1.209 及以上，Pro、Max、Team、Enterprise 可用）：

- 只有你 **claude.ai 账号里的连接器**能被页面调用；你本地配置的 MCP 服务器只能在"做页面时"提供数据，发布后的页面调不了。
- 页面打开时，是用**查看者自己的账号**去调用连接器。所以两个人看同一个看板，看到的数据可能不同；对方没连接该应用，就看不到实时区块。第一次调用前，系统会请查看者授权。
- 如果页面带有"发消息""改状态"这类按钮，点击时用的也是**点击者自己的账号**。
- 管理员可以在后台单独开关"Enable artifact connectors"。
- 匿名的公开链接查看者看不到实时区块。

## 页面的限制

- 单页静态页，不能有多个子页面；相对链接不可用。
- 页面只能从少数几个公共 CDN 加载脚本库，外部图片和其他外部资源会被拦截，图片通常内嵌。
- 页面体积需在 16 MiB 以内。
- 生成页面消耗的额度比纯文字多：多用 SVG 和简单样式，少用大图，大数据先汇总再展示。

## 动手任务

1. 先确认已用 `/login` 登录 claude.ai 账号。
2. 用虚构数据做一个"某公司季度销量汇报"页（比如"星河贸易有限公司"，三条产品线、四个季度）。
3. 让 Claude 再加一块"风险与建议"，重新发布，观察同一个链接是否自动更新。
4. 在 Share 里把它设为只有自己可见，再看一眼版本选择器。

## 小结

- Artifact 是"可分享、可持续更新"的成果页，默认私有。
- 先查套餐、登录方式、模型来源和组织策略四项条件。
- 实时数据靠 MCP 连接器，且以**查看者自己的账号**去调用。
- 分享前检查内容，公开链接慎用。
