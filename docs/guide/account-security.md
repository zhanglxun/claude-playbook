# 账号安全设置

学完这页，你能完成账号开通后的基础安全设置，并知道日常使用中要避开哪些做法。

账号里会有你的对话记录和上传的资料，保护好账号就是保护业务信息。以下是通用建议，具体选项以官方帮助中心为准。

## 开通后第一件事

1. **使用公司可长期控制的邮箱**：不要用即将离职同事的个人邮箱，避免人员变动后账号失控。
2. **保护好登录方式**：Claude 的登录方式（如邮箱验证链接、第三方账号登录等）以官方登录页为准。<!-- TODO 核实：个人账号是否提供独立的两步验证设置；目前未在公开资料中确认，写法保守 --> 不论哪种方式，都要给**登录所用的邮箱或第三方账号**设置强密码并开启两步验证。
3. **团队版**：由管理员按公司要求配置统一登录和成员管理。
4. **检查隐私与数据设置**：在账号设置中查看与对话数据相关的选项，了解它们的含义。

## 什么是强密码和两步验证

- **强密码**：足够长，不与其他网站重复，不含生日、手机号等容易猜到的信息。建议用密码管理工具保存。
- **两步验证**：登录时除了密码，还要再确认一次（例如手机上的验证码）。即使密码泄露，别人也进不来。

## 日常注意

| 要做 | 不要做 |
|---|---|
| 一人一个账号，各自登录 | 多人共用一个账号，或转借、转售账号 |
| 在自己受管理的电脑上使用 | 在公共电脑上保持登录；用完要退出 |
| 保持相对稳定的登录环境（常用设备、常用网络） | 频繁在不同设备、不同网络间来回切换登录 |
| 遵守 Claude 的服务条款和使用政策 | 做违反条款的事，导致账号被限制或封禁 |
| 敏感信息先脱敏再使用 | 把客户个人信息、合同金额、密码等直接贴进对话 |

## 保护敏感信息

- 不上传不该外传的文件
- 客户姓名、联系方式、账号密码、精确金额，必要时替换成代号
- 不确定能不能给 AI 看的内容，先问公司的信息安全负责人

更多规则见 [使用规范与数据安全](/security/)。

## 课堂练习：安全自查清单

逐项勾选：
- [ ] 登录邮箱/第三方账号是可长期控制的
- [ ] 该邮箱/账号已设置强密码并开启两步验证
- [ ] 没有与他人共用账号
- [ ] 已查看账号的隐私与数据选项
- [ ] 知道哪些信息不能贴给 AI

## 小结

- 强密码 + 两步验证 + 一人一号 + 稳定环境 + 遵守条款 + 保护敏感信息
