# 账号类型怎么选

学完这页，你能根据自己的使用情况，判断适合免费版、个人付费版还是团队版。

::: warning 注意
套餐名称、功能和额度会调整，本页不写具体价格和数字，请以 [Claude 官方价格页](https://claude.com/pricing) 为准。本教程为独立编写，不代表官方。
:::

## 常见类型

| 类型 | 适合谁 | 特点（以官方页面为准） |
|---|---|---|
| 免费版（Free） | 想先体验的人 | 可以对话、搜索、体验基础功能；部分功能和模型不包含 |
| 个人付费版（Pro） | 个人日常使用 | 更多用量，包含 Projects、研究功能、Claude Code 等 |
| 高用量版（Max） | 重度使用者 | 比 Pro 更高的使用额度和更优先的访问 |
| 团队版（Team） | 多人协作的团队 | 统一管理成员与账单、共享项目、支持单点登录 |
| 企业版（Enterprise） | 大型企业 | 在团队版基础上提供更多管理、合规与安全能力 |

## 额度是什么

付费版有"使用额度"：你用得越多、处理的资料越长、选用的模型越强，消耗越快。额度用完需要等待重置，或升级套餐。具体规则以官方说明为准。

## 怎么选

- **只是想试试**：先用免费版，看是否适合你的工作
- **每周都要用，需要 Projects 和文件分析**：个人付费版
- **每天大量使用，经常提示额度不足**：高用量版
- **一个团队要一起用，共享资料**：团队版，由管理员统一管理
- **对安全合规有更高要求的大型组织**：与官方销售了解企业版

## 选择前问自己

| 问题 | 影响 |
|---|---|
| 我一周大约用几次？ | 决定是否需要付费 |
| 是否需要上传大量文件？ | 影响额度需求 |
| 是否需要多人共享项目？ | 团队版 |
| 公司对数据管理有要求吗？ | 团队版或企业版 |

## 课堂练习

用下面的提示词，让 Claude 帮你整理选型思路（它不了解最新套餐，仅作思路参考，最终以官方页面为准）：

```text
我的使用情况是：【每周使用频率】、【主要用来做什么】、【团队人数】。请列出我在选择 AI 助手套餐时应该考虑的 5 个问题，并提醒我哪些信息需要去官方页面核对。
```

## 小结

- 先体验、再按使用强度升级；多人协作用团队版
- 价格和额度只看官方页面
