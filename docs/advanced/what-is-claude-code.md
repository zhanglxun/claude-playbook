# Claude Code 是什么

> 内容核对日期：2026-10-18；涉及的功能以 Claude Code 当时版本为准，请以官方文档为准。

## 学完这页你能…

- 用一句话说清 Claude Code 和网页版 Claude 的区别
- 举出至少三种适合交给它的业务任务
- 知道 Claude Code 可以在哪些地方使用，本课程选哪一种

## 一句话区别

**网页版 Claude 是"你把资料递给它，它在对话框里回答"；Claude Code 是"它坐到你的电脑前，自己打开文件干活"。**

| | 网页版 / 桌面端对话 | Claude Code |
|---|---|---|
| 资料从哪来 | 你上传或粘贴 | 它直接读你指定文件夹里的文件 |
| 结果去哪 | 在对话框里，需要你复制保存 | 直接写成文件（报告、表格、汇总）存在你的文件夹里 |
| 能做的事 | 回答、分析、写作 | 在此基础上还能读多个文件、批量改文件、新建文件、运行工具 |
| 一次处理的量 | 受上传数量限制 | 一个文件夹里几十上百份文件也能逐个读 |
| 你需要做的 | 搬运资料、保存结果 | 交代任务、检查结果、批准关键操作 |

它的底层仍然是同一个 Claude 模型，会遇到同样的局限：可能出错、可能"一本正经地编"，所以**检查输出**依然是你的责任（见 [AI 的能力与局限](/guide/limits)）。区别在于，它多了一双"手"：能读、能写、能执行。

::: info 名字里的"Code"
Claude Code 最初是为程序员设计的，所以叫"Code"。但"读文件、改文件、整理、批量处理"这些能力对业务工作同样有用。本篇不讲编程，只讲业务用法。
:::

## 它是怎么工作的（大白话版）

当你给 Claude Code 一个任务，它大致会这样循环：

1. **看**：先读相关文件，了解情况
2. **想**：决定下一步做什么
3. **做**：修改文件、新建文件、或运行一个小工具
4. **查**：看结果对不对，不对就再调整
5. 全部完成后向你汇报

关键点：**在"做"的这一步，它会按你设定的权限来决定要不要先问你**。这就是为什么 [3.5 权限与安全](/advanced/permissions) 是必学内容。

## 典型业务用法

下面的例子都不需要写代码，只需要用日常语言描述。

| 业务场景 | 你说的话（示意） | 它做的事 |
|---|---|---|
| 资料整理 | "把这个文件夹里的 30 份调研访谈记录，整理成一张汇总表" | 逐份读取，提取关键信息，生成表格文件 |
| 写报告 | "根据这些资料写一份竞品对比报告，参照我的模板" | 读资料和模板，生成报告文档 |
| 批量处理 | "把所有文件按'日期_主题'的格式重命名" | 批量改名并给出清单 |
| 数据核对 | "对比这两张报价表，列出不一致的地方" | 读取两个表，输出差异清单 |
| 周期性工作 | "每周把新增的行业新闻整理成一页摘要" | 配合后面学的技能和定时功能自动完成 |
| 知识沉淀 | "把本季度所有会议纪要归档并建立目录" | 分类、命名、生成索引 |

案例中的公司均为虚构，例如"云帆咨询""启明贸易"。你在练习时也请用虚构或可公开的资料。

## 可以在哪里使用

Claude Code 有多种使用入口，它们共用同一个引擎，所以你的设置和记忆规则可以通用：

| 入口 | 特点 | 适合谁 |
|---|---|---|
| **VS Code 扩展** | 在一个免费的编辑软件里，有图形化的对话面板，修改前后对比一目了然 | **本课程采用**，最适合零基础 |
| 桌面应用（Claude 桌面端的"Code"标签） | 独立应用，可以并排运行多个会话，图形化查看修改 | 不想装编辑软件的人 |
| 终端（命令行） | 功能最全，靠敲命令操作 | 习惯命令行的人 |
| 网页版和手机 | 在浏览器或手机上发起、查看任务 | 外出时查看进度 |
| JetBrains 等其他编辑器 | 面向开发人员 | 研发人员 |

> 提示：各入口支持的功能和所需套餐略有差别，部分功能只在终端里提供。本课程以 VS Code 为主，需要时会特别说明。

## 它不能做什么、要小心什么

- **它不是万能的**：模型的幻觉、知识截止日期这些局限依然存在
- **它能改你的文件**：所以要养成习惯，在重要文件夹上工作之前先备份一份
- **它只应该在你指定的文件夹里工作**：不要把整个"文档"盘或含客户机密的文件夹交给它
- **它读到的内容会发送给 Anthropic 的服务处理**：不要放入不该外传的资料，规则见 [使用规范与数据安全](/security/)

## 课堂练习

不用安装任何东西，只做一次思考：

1. 写下你日常工作中最耗时的三件"读多个文件、整理成一份成果"的事
2. 每件事写一句话描述："输入是什么文件，期望的输出是什么文件"
3. 按"重复频率"和"出错后果"给三件事排序，**频率高、出错后果小**的最适合先尝试

## 小结

- Claude Code = 同一个 Claude + 在你电脑上读写文件、执行任务的能力
- 价值在于省去"搬运资料、保存结果"的环节，让你专注于交代任务和把关结果
- 本课程选 VS Code 作为主要入口，下一页就动手安装
