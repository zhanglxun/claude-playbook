**适合谁**：想把 Claude Code 放进脚本、定时任务、构建流程，或想在自己的程序里嵌入一个"能读文件、跑命令的智能体"的人。

## 一、claude -p：不打开界面，直接给答案

平时你在终端输入 `claude` 进入对话界面。加上 `-p`（全称 `--print`）就变成**非交互模式**：给一句话，它执行完直接输出结果然后退出，适合放进脚本。

最小示例：

```text
claude -p "这个文件夹里的 auth 模块是做什么的？"
```

成功时退出码为 0，失败时为非 0，脚本可以据此判断。

### 管道：把别的程序的输出交给它

非交互模式会读取标准输入，所以可以像其他命令行工具一样串联：

```text
cat build-error.txt | claude -p "用一两句话说明这个构建错误的根本原因" > output.txt
```

注意：管道输入上限为 10MB，更大的内容请先存成文件，在提示词里写文件路径。

### 让输出能被程序读取

`--output-format` 控制输出格式：

- `text`（默认）：纯文本
- `json`：带会话编号、用量等信息的 JSON，答案在 `result` 字段
- `stream-json`：逐行输出的 JSON，适合实时显示

```text
claude -p "总结这个项目" --output-format json
```

还可以用 `--json-schema` 要求输出符合你定义的结构，结果会出现在 `structured_output` 字段。

### 权限：没有人点"同意"怎么办

无界面运行时没有人可以点确认，所以要**事先说明允许做什么**：

```text
claude -p "运行测试并修复失败项" --allowedTools "Bash,Read,Edit"
```

也可以用 `--permission-mode` 指定整体模式，如 `acceptEdits`（自动接受文件修改）、`dontAsk`（凡是需要询问的一律拒绝，适合严格受限的自动化）、`auto`（由分类器代替人审查）。官方提醒：**没有显式设置模式时，会使用内置的默认起始模式，可能就是自动模式**，所以自动化脚本里建议明确写出你想要的模式，不要依赖默认值。

### 其他实用选项

- `--continue` / `--resume 会话编号`：接着上一次的对话继续追问。
- `--bare`：跳过自动加载钩子、技能、插件、MCP、CLAUDE.md，启动更快，**每台机器结果一致**，官方推荐用于脚本和 CI，并说明未来会成为 `-p` 的默认模式。注意它不使用订阅登录，需要设置 `ANTHROPIC_API_KEY`。
- `--append-system-prompt`：在保留默认行为的基础上追加你的要求。
- `--max-turns`：限制来回轮数，控制成本。

### 无界面运行下不能用什么

电脑操作（Computer use）、需要交互的命令（如 `/login`）、Artifacts 默认关闭等，在 `-p` 模式下不可用或默认关闭，详见各功能页面。

## 二、Agent SDK：把它变成你程序里的一个零件

**Agent SDK** 是官方提供的程序库（Python 和 TypeScript 两个版本），把 Claude Code 的能力——内置工具（读写文件、跑命令、搜索网页）、权限控制、会话管理、钩子、子代理、MCP——放进你自己的程序里。

三种相近概念怎么区分：

| 想做什么 | 用什么 |
|---|---|
| 自己在终端里交互式工作，或跑一次性任务 | Claude Code 命令行 |
| 在自己的 Python / TypeScript 程序里嵌入"会自己规划步骤、调用工具"的智能体 | Agent SDK |
| 只是调用模型接口，工具循环自己写 | Claude API 的客户端 SDK |

`claude -p` 其实就是用命令行形式使用 Agent SDK：用别的语言写程序时，也可以把 `claude -p ... --output-format json` 当子进程调用。

最小概念示例（具体包名与接口请看官方快速入门）：

```text
1. 安装 SDK（Python 或 TypeScript 版本）
2. 设置 API 密钥
3. 向智能体提交任务："找出 auth.py 里的 bug 并修复"
4. 读取它一路上的消息和最终结果
```

## 动手任务

1. 在一个演示文件夹里，执行：

```text
claude -p "列出这个文件夹里每个文件的用途，每个文件一行" --output-format json
```

2. 找到输出里的 `result` 字段，确认是你要的答案。
3. 试着把某个日志文件用管道交给它总结。
4. 想一想：你们团队里有哪些"每天/每次重复做的检查"，可以变成一条 `claude -p` 命令？

## 小结

- `claude -p` = 无界面、一次性、可串联、可脚本化。
- 无人值守时，必须事先写清权限，别依赖默认模式。
- Agent SDK = 把同样的能力放进你自己的 Python/TypeScript 程序，认证用 API 密钥。
