# 界面与模型选择

学完这页，你能在网页端、桌面端、手机端顺利开始对话，并根据任务挑选合适的模型。

> 本教程为独立编写，非 Anthropic 官方内容。界面会随版本更新，名称和位置以官方为准。

## Claude 在哪里用

| 入口 | 适合场景 | 说明 |
|---|---|---|
| 网页端（claude.ai） | 日常办公首选 | 打开浏览器登录即可，功能最全 |
| 桌面应用 | 经常使用、想一键唤起 | 装在电脑上，和网页端是同一个账号，对话互通 |
| 手机应用 | 路上随手问、拍照提问 | 对话记录同步，适合快速查询和拍照识别 |

同一个账号在三个入口看到的历史对话是同步的。重要工作建议在电脑上完成，手机用来补充。

## 认识主界面

- **输入框**：对话的核心。可以打字，也可以点附件按钮上传文件、图片。
- **左侧边栏**：新建对话、历史对话列表、Projects、Artifacts 等入口。
- **模型选择器**：输入框附近，显示当前使用的模型，点开可以切换。
- **功能开关**：联网搜索、研究、连接的应用等，通常在输入框附近的菜单里打开或关闭。

> 提示：不同套餐、不同版本看到的开关可能不同，找不到时先看官方帮助中心。

## 新建对话与历史对话

**一个话题一个对话。** Claude 只会参考当前对话里的内容。这有两个好处：

1. 资料不会串到别的话题，答案更干净。
2. 对话太长时，Claude 容易"忘掉"前面的细节，新开对话更稳。

经验做法：
- 换一个主题，就点"新对话"。
- 要接着以前的工作，从历史对话里找回来继续，或用 [Projects](/basics/projects) 把资料固定下来。
- 对话标题可以改名，方便日后查找，例如"德国市场调研-第一轮"。

## 不同模型怎么选

可以把模型想成不同级别的员工：有的特别聪明但慢一些、费额度；有的反应快、适合处理大量简单活。Claude 目前提供四档：

| 模型 | 定位 | 适合的业务任务 |
|---|---|---|
| Claude Fable 5.1 | 最强，处理长而难的任务；需要手动选择，不是默认模型 | 复杂研究、长流程的综合分析 |
| Claude Opus 5.5 | 复杂推理，多数主要套餐的默认模型 | 方案规划、深度分析、撰写重要文稿 |
| Claude Sonnet 5.5 | 日常主力，速度和质量均衡 | 日常整理、写作、数据处理 |
| Claude Haiku 5.5 | 快、省 | 简单、批量、重复的小任务，如分类、改写 |

### 一个简单的选择办法

1. **不确定时用默认模型**，通常够用。
2. **任务难、结果重要**（如给管理层的分析报告）：换更强的模型。
3. **任务简单、量大**（如把 50 条客户反馈归类）：用更快的模型，省时间和额度。
4. **同一个任务可以换档试一试**：先用快的出初稿，再用强的精修。

强模型通常也更耗用量额度。各套餐的额度规则请看 [Anthropic 官方页面](https://claude.com/pricing)，本教程不列具体数字。

## 课堂练习

1. 打开 Claude，新建一个对话，把标题改成"模型对比练习"。
2. 选一个你工作中的真实问题（不含敏感信息），例如"如何向客户解释交期延迟"。
3. 用两个不同的模型各回答一次，比较：速度、内容深度、语气。
4. 写下一句结论：这类任务我日常用哪一档？

## 小结

- 网页端、桌面端、手机端同账号，对话同步。
- 一个话题一个对话，长对话容易遗忘细节。
- 模型选择看任务：难而重要用强的，简单批量用快的。
