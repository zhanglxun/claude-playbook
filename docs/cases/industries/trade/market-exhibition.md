# 海外市场与展会资料整理

参加展会或开拓新国家前后，业务员会面对一大堆资料：展商名录、行业报告、官网信息、名片和展会笔记。**整理这些资料是 Claude 的强项，但事实和数据要核对。**

> 案例为虚构：某家居出海品牌准备参加"示意国际家居展"，并研究"某国"的家居零售渠道。展会名称、公司名均为示意。

## 分析框架

### 展前

1. **目标**：这次展会想接触谁、达成什么（如 20 家潜在零售商）。
2. **名录筛选**：按品类、国家、规模筛出优先拜访对象。
3. **背景准备**：每家重点展商的公开信息摘要和沟通切入点。

### 展后

4. **笔记整理**：把现场记录归一成统一格式（对方、需求、跟进动作）。
5. **分级跟进**：按意向分 A/B/C，设定跟进时间与内容（可衔接[客户开发信与跟进](/cases/industries/trade/outreach)）。
6. **复盘**：哪些渠道有效、哪些资料需要补充。

### 海外市场资料

渠道、用户偏好、准入要求的整理方法与[市场分析](/cases/common/market-analysis)一致：框架 + 公开资料 + 出处标注。

## 示范提示词

### 一：筛选展商名录

把公开的展商名录（Excel 或文本）上传：

```text
这是【展会名称】的公开展商名录，共【N】家。我们是做【产品类别】的品牌，想找【渠道类型，如在线零售商、连锁家居店】。
请：
1. 按"与我们的匹配度"把展商分为 A/B/C 三级，并说明分级依据（只依据名录中的信息）
2. 输出表格：展商名称 | 国家 | 主营品类 | 匹配等级 | 判断依据 | 需要进一步查证的信息
3. 名录中信息不足的展商，标为"待查证"，不要猜测
```

### 二：展会笔记整理

把展会现场的零散笔记（已删除个人联系方式，或用代号代替）粘贴：

```text
这是我在展会上的零散记录（已脱敏）：
【粘贴笔记】
请整理成表格：对方（代号）| 国家 | 主营品类 | 关注的产品 | 提出的需求 | 意向（A/B/C）| 建议跟进动作 | 建议跟进时间
笔记没有提到的内容填"未记录"。表格后列出 A 级客户的跟进要点（每家 2 到 3 句）。
```

### 三：海外市场资料汇总

```text
请阅读我上传的关于【国家】家居市场的公开资料，整理：
1. 主要零售渠道及特点
2. 消费者偏好的 3 个要点
3. 进入该市场需要关注的准入事项（认证、标签、关税等），列出名称即可
每条结论后注明出处文件名；所有法规、认证名称、数字单独列表，标注"需到官方渠道核对"。
```

## 课堂练习

1. 用一份虚构名录（20 行即可）完成分级，检查 Claude 的分级依据是否站得住。
2. 写 10 条杂乱的"展会笔记"，让 Claude 整理成表，再手工补充缺项。
3. 用提示词三整理一份公开资料，挑 3 条核对出处。

## 注意事项

- **事实要核对**：展会日期、规模、准入法规、关税等，以展会官网和政府官方发布为准。<!-- TODO 核实：如需列出各国准入查询的官方入口，应逐一确认链接后再补充 -->
- **名片和联系方式属于个人信息**：整理时用代号，不要把真实姓名、邮箱批量上传；使用方式遵循公司规定及当地法规。
- **只用公开渠道资料**：展商名录等取自展会公开页面；不要采集需要登录或受限制的内容。
- 笔记里的竞品信息，只作内部参考，不在对外邮件中引用。

## 两种做法对照

### 网页版做法

- 名录和资料较少时，直接上传文件，用提示词一、二、三完成。
- 同一展会的多份资料建一个 [Projects](/basics/projects)，展前展后接续使用。
- 适合：单个展会、名录不超过几百行。

```text
请阅读我上传的展商名录，按与我们产品的匹配度分为 A/B/C，输出表格并说明依据，信息不足的标"待查证"。我们的产品是【产品类别】，目标渠道是【渠道类型】。
```

### Claude Code 做法

- 把名录、展商官网摘要、展会笔记、行业资料放进 `展会资料/` 文件夹，一次读取。
- 让它生成分级名录、展后跟进清单和展会复盘报告，一并保存为文件。
- 把"脱敏规则、分级标准"写入 `CLAUDE.md`，每次展会复用；也可做成 [Skills](/advanced/skills)。

```text
请读取 展会资料/ 文件夹下所有文件：名录.xlsx、笔记.txt 和 行业资料/ 里的 PDF。
1. 按匹配度把名录分为 A/B/C，保存为 展商分级.xlsx（列：展商、国家、主营品类、等级、依据、待查证信息）。
2. 把笔记.txt 整理成 展后跟进清单.xlsx（列：对方代号、需求、意向、跟进动作、建议时间）。
3. 写一页展会复盘报告 展会复盘.docx，内容含：收获、A 级客户要点、下次改进建议。
所有事实性内容注明出处文件；资料没有的写"待查证"。
```

了解更多：[Claude Code 是什么](/advanced/what-is-claude-code)。

## 小结

展会资料整理的价值在于"快速分级、不漏跟进"。Claude 负责归类和起草，事实、数据和个人信息的处理由人把关。
