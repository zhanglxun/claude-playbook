# 贸易行业

本行业篇面向外贸业务员、跟单和业务管理者。外贸工作的特点是：**文字多、语言杂、资料散、数字要准。** 这恰好是 Claude 擅长的整理和起草工作，也是最需要人工把关的地方。

> 案例中的公司、产品、客户均为虚构，如"某家居出海品牌""示意客户 A"，数据仅作示意。

## 其他常见小场景

### 外贸邮件快速起草

```text
你是一名专业的外贸业务员。请根据以下要点写一封英文邮件：
- 收件人：【客户类型，如：欧洲家居零售商采购经理】
- 目的：【报价跟进 / 新品推荐 / 交期说明】
- 要点：【列出 3 到 5 个要点】
语气专业友好，150 词以内。给出邮件标题（3 个备选）和正文。
```

### 产品资料翻译与本地化

- 不只是翻译，要求"按目标市场的表达习惯改写"。
- 提供术语表，保证专业词汇统一，如"折叠凳""承重"的固定译法。
- 让 Claude 同时列出"翻译时做了哪些改写、哪里存疑"，方便人工校对。
- 涉及规格、认证、法规的表述，由懂行的人最终核对。

### 报表整理

上传订单或出货表格（先删去客户真实名称和联系方式），让 Claude 汇总、分类并指出异常数据，例如数量与金额对不上、日期倒置、重复订单。异常项只是线索，须回到原始单据核实。

## 贸易场景的三条红线

1. **价格和承诺必须人工确认**：邮件、报价里的价格、交期、付款方式、质量承诺，由业务负责人确认后再发出，不能直接复制 Claude 的内容。
2. **客户资料先脱敏**：把真实客户名、邮箱、电话、合同金额替换成"客户A""【邮箱】"后再上传，规则见 [使用规范与数据安全](/security/)。
3. **事实性内容要核对**：关税、认证、法规、展会日期等，让 Claude 标注来源，再到官方渠道核对。

## 两种做法怎么选

| 情况 | 建议 |
|---|---|
| 单封邮件、单个询盘 | 网页版，对话式修改 |
| 长期固定客户群、固定话术 | 网页版 [Projects](/basics/projects)，沉淀产品资料与语气要求 |
| 一个文件夹几十份询盘、展会名录批量处理 | Claude Code，读取整个文件夹并输出汇总表 |

详见 [Claude Code 是什么](/advanced/what-is-claude-code)。

## 小结

贸易业务用 Claude 的原则：它负责起草、整理、归纳，人负责确认价格、承诺和事实。先学三个场景页，再回来结合自己的客户群调整提示词。
