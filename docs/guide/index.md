# 课程介绍

## 这门课适合谁

- 刚开通 Claude、希望快速上手的企业员工
- 需要做产品调研、市场分析、外贸沟通的业务人员

## 学习路线

| 章节 | 内容 | 建议时长 |
|---|---|---|
| 入门篇 | Claude 是什么、账号类型、安全设置 | 20 分钟 |
| 基础篇 | 提示词、文件分析、Projects | 40 分钟 |
| 场景篇 | 产品调研、市场分析、竞品对比 | 40 分钟 |
| 行业篇 | 按所在行业选学 | 20 分钟 |

## 学完你能做到

1. 写出结构清晰、结果稳定的提示词
2. 让 Claude 读懂你的产品资料和表格数据
3. 用固定的分析框架完成一份产品调研或市场分析初稿
