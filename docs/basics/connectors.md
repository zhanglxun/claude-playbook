# 连接外部应用与技能

学完这页，你能在 Claude 网页端或桌面端连接常用应用，启用现成技能，并清楚知道其中的权限与风险。

> 本页只讲在 Claude 网页端、桌面端的使用。在 Claude Code 里的配置属于高级篇内容。

## 两个新概念

### MCP / 连接器：给 Claude 接上"外接设备"

Claude 默认只能看到你发给它的内容。**MCP** 是一套让 AI 连接外部应用的通用标准，你可以把它理解成"USB 接口"：接上之后，Claude 就能读取（有时也能操作）你授权的应用，比如日历、云盘、邮箱、项目管理工具。在 Claude 的界面里，这类功能一般叫"连接器（Connectors）"。

例子：连接日历后，你可以说"帮我看看下周哪天下午比较空，适合安排客户会议"，不用自己截图或粘贴。

### Skills / 技能：可复用的做事手册

**Skills（技能）** 是一份写好的"做事流程"，告诉 Claude 遇到某类任务该怎么做，比如"怎么生成规范的 Excel 报表""怎么写符合公司格式的 Word 文档"。需要时 Claude 会自动调用，不用你每次重新描述。

打个比方：连接器是"能碰到什么东西"，技能是"知道该怎么做这件事"。

## 怎么连接应用

大致步骤（具体名称以官方界面为准）：

1. 进入设置，找到"连接器"相关页面，或在对话输入框附近的菜单里选择添加连接器。
2. 在目录里选择要连接的应用，例如日历、云盘。
3. 按提示登录该应用并同意授权。
4. 回到对话，在输入框附近的菜单里确认该连接器已开启。
5. 用自然语言提需求，Claude 会在需要时读取该应用的数据。

在团队版或企业版中，哪些连接器可用往往由管理员决定，需要先联系管理员。

## 示范提示词

```text
请查看我日历里【下周】的安排，找出两个适合开 60 分钟客户沟通会的时间段，并说明理由。
只读取，不要创建或修改任何日程。
```

```text
请在我的云盘中查找名为【文件名关键词】的文件，读完后总结要点，并告诉我你读了哪些文件。
```

提示词里加上"只读取，不要修改"是个好习惯。

## 怎么启用技能

1. 进入设置，找到"技能"相关页面（名称以实际界面为准）。
2. 浏览官方提供的现成技能，例如生成表格、文档、演示稿的技能，按需开启。
3. 打开后，直接说出任务，例如"做一份 Excel 销售汇总"，Claude 会在合适时调用对应技能。
4. 团队版里，管理员可能提供团队共用的技能，按公司规则使用。

自己编写技能属于进阶内容，将在高级篇讲解。

## 权限与风险提醒

连接外部应用意味着把一部分数据通道交给了 AI，务必谨慎。

| 风险 | 做法 |
|---|---|
| 连接了不可信的应用 | 只连接来源可靠、有官方背书或公司批准的应用 |
| 授权范围过大 | 只授予完成工作所需的最小权限，能"只读"就不要"可写" |
| 误操作 | 让 Claude 执行发邮件、改日程、删除文件前，要求先给你确认 |
| 数据泄露 | 不连接存放高度敏感资料的账号；敏感文件放在不被连接的位置 |
| 外部内容里的恶意指令 | 网页、邮件中可能夹带诱导 AI 做事的话，涉及外发、转账、删除的操作务必人工确认 |
| 离职或不再使用 | 定期检查已授权的应用，不用的及时断开 |

几条规矩：

1. 先在不重要的数据上试用，熟悉后再扩大范围。
2. 遵守公司信息安全制度，不确定的先问 IT 或管理员。
3. 重要输出仍要人工核对，不能因为"读了真实数据"就免检。

## 课堂练习

1. 在允许的情况下，连接一个只读的应用（例如日历），让 Claude 总结下周的安排。
2. 检查授权页面，确认它能读什么、不能做什么。
3. 开启一个现成技能，让 Claude 生成一份简单的表格或文档。
4. 练习结束后，思考一下：哪些应用你绝对不会连接？为什么？

## 小结

- 连接器让 Claude 能接触你的应用数据，技能让它掌握固定流程。
- 只连接可信应用，授权遵循最小范围，敏感操作先确认。
