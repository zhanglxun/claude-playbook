# 询盘与报价回复

收到询盘后，业务员要做三件事：**判断值不值得跟、搞清楚客户要什么、快速专业地回复。** Claude 能帮你把这三步压缩到几分钟，但报价本身必须由你决定。

> 案例为虚构：某家居出海品牌收到"示意客户 B"关于折叠收纳凳的询盘。邮件内容、数量、价格均为示意。

## 分析框架

| 步骤 | 要回答的问题 |
|---|---|
| 1. 提取需求 | 产品、规格、数量、目的地、交期、付款偏好各是什么 |
| 2. 评估意向 | 是真实采购、比价，还是随手问；依据是什么 |
| 3. 找出缺失 | 报价前还缺哪些信息，需要向客户确认什么 |
| 4. 起草回复 | 先回答客户问题，再提出澄清和下一步 |
| 5. 人工确认 | 价格、交期、条款等由负责人确认 |

## 示范提示词

### 一：解析询盘

先把询盘邮件的客户姓名、邮箱、电话替换为"客户B""【邮箱】"后粘贴：

```text
这是一封海外客户的询盘邮件（已脱敏）：
【粘贴询盘内容】

请：
1. 提取需求，用表格列出：产品、规格、数量、目的地、期望交期、付款方式、其他要求；邮件没写的填"未提及"
2. 判断客户意向（高/中/低），并给出依据（只依据邮件内容）
3. 列出报价前我需要向客户确认的问题（不超过 5 个）
4. 标出邮件中的疑点或风险（如要求不寻常的付款方式、信息矛盾）
```

### 二：起草回复（不含价格）

```text
请根据上面的分析，用英文起草回复邮件：
- 先感谢并简要回应客户的核心需求
- 说明我们可以提供的产品类型：【产品简介】
- 礼貌地询问第 3 步列出的问题
- 价格和交期处写成【待确认：价格】【待确认：交期】占位，不要自行填写数字
- 控制在 180 词以内，语气专业友好
邮件后另附一段中文，列出发出前我必须确认的事项。
```

### 三：整理成报价邮件

在你确定价格后：

```text
我已确认以下报价信息：
- 产品：【名称、规格】 数量：【数量】
- 单价：【你确认的价格与币种】 贸易条款：【如 FOB、CIF 及港口】
- 交期：【你确认的交期】 付款方式：【你确认的方式】 报价有效期：【日期】
请整理为一封专业的英文报价邮件，附一个清晰的报价表格。只使用我提供的信息，不要新增任何条款或数字。
```

## 课堂练习

1. 用虚构询盘（可由讲师提供，或自己编一封）完成第一步解析。
2. 检查 Claude 提出的澄清问题，哪些是真正影响报价的，哪些可以删。
3. 两人一组：一人写"问题多、信息少"的询盘，另一人用提示词应对。

## 注意事项

- **价格和承诺必须人工确认**：提示词二故意要求用占位符。任何数字、交期、质保承诺，都应由你填入并复核。
- **客户资料先脱敏**：姓名、邮箱、电话、公司名、地址都先替换。历史成交价、合同条款不要上传。
- **警惕异常询盘**：对于要求预付款到陌生账户、信息前后不一等情况，Claude 的判断只是提示，须按公司风控流程处理。
- **术语核对**：贸易术语、认证、关税等表述请对照官方资料确认。<!-- TODO 核实：贸易术语版本与关税描述需以官方资料为准，教程未写具体条款 -->

## 两种做法对照

### 网页版做法

- 把常用的产品资料、报价模板、回复语气写入 [Projects](/basics/projects)，每封询盘粘贴脱敏文本即可。
- 逐封解析、起草、修改，适合每天几封。
- 注意价格表若含成本信息，不要放入知识库。

```text
按项目指令，解析下面这封脱敏询盘，输出需求表、意向判断、需向客户确认的问题，并起草不含价格的英文回复。询盘内容：【粘贴】
```

### Claude Code 做法

- 把一批询盘保存为文件夹中的文本或 Excel（先脱敏），一次处理。
- 让它输出"询盘汇总表"（需求、意向、待确认问题），并为每封生成回复草稿，价格处用占位符。
- 在 `CLAUDE.md` 写明"不得填写价格和交期""所有草稿标注待人工确认"；日常流程可固化为 [Skills](/advanced/skills)。

```text
请读取 询盘/ 文件夹下的所有 .txt 文件（每个文件是一封已脱敏的询盘）。
1. 汇总为 询盘汇总.xlsx，列：文件名、产品、规格、数量、目的地、期望交期、意向（高/中/低）及依据、报价前需确认的问题。
2. 为每封询盘写一份英文回复草稿，保存到 回复草稿/ 文件夹，文件名与原文件对应。
价格、交期一律写成【待确认】，不要自行填写；邮件中没有的信息写"未提及"。
```

了解更多：[Claude Code 是什么](/advanced/what-is-claude-code)。

## 小结

询盘处理 = 提取需求 + 评估意向 + 补齐缺失 + 起草回复 + 人工确认。Claude 提速，价格和承诺永远由人定。
