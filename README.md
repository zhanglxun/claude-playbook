# Claude 实战手册（claude-playbook）

面向企业业务人员的 Claude 应用培训教程：账号选择、提示词写法、文件分析，以及产品调研、市场分析等场景实战。

在线阅读：https://zhanglxun.github.io/claude-playbook/

> 本教程为独立编写的培训资料，非 Anthropic 官方出品。Claude 是 Anthropic 的商标。

## 本地运行

```bash
npm install
npm run docs:dev
```

## 目录

| 章节 | 内容 |
|---|---|
| 入门篇 | Claude 是什么、能力与局限、账号类型、安全设置、概念地图 |
| 基础篇 | 提示词、文件与表格分析、Projects、Artifacts、联网研究、连接外部应用与技能 |
| 高级篇 | Claude Code 业务应用：权限、CLAUDE.md、Skills、MCP、子代理与 Agent 循环、数据沉淀 |
| 场景与行业篇 | 通用场景（产品调研、市场分析、竞品对比）和行业场景（贸易等） |
| 工具与规范 | 提示词模板库、使用规范、常见问题、术语表与速查表 |

> 详细大纲见 [OUTLINE.md](OUTLINE.md)（草案，待确认）。
