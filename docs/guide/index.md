# 课程介绍

## 这门课适合谁

- 刚开通 Claude、希望快速上手的企业员工
- 需要做产品调研、市场分析、外贸沟通的业务人员

## 学习路线

| 章节 | 内容 | 自学时长（估） |
|---|---|---|
| 入门篇 | Claude 是什么、能力与局限、账号类型、安全设置、概念地图 | 约 2 小时 |
| 基础篇 | 提示词、文件分析、Projects、Artifacts、联网研究、连接应用 | 约 3.5 小时 |
| 高级篇 | Claude Code 业务应用（核心课必学，选学专题按需） | 核心约 6 小时 |
| 场景与行业篇 | 通用场景 + 按所在行业选学 | 按需 |
| 工具与规范 | 提示词模板、使用规范、常见问题、术语表 | 随用随查 |

## 学完你能做到

1. 写出结构清晰、结果稳定的提示词
2. 让 Claude 读懂你的产品资料和表格数据
3. 用固定的分析框架完成一份产品调研或市场分析初稿
