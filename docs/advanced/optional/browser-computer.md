# 浏览器与电脑操作

> 内容核对日期：2026-10-18；选学内容。部分功能为研究预览/公测，且按套餐和版本开放，请以官方文档为准。

**适合谁**：需要让 Claude 去点网页、填表单、操作某个只有图形界面的软件，或者想让它自己验证"做出来的东西真的能用"的人。

**学完能**：说清三种"动手"方式（Claude in Chrome、桌面应用内置浏览器、电脑操作）各自能做什么、不能做什么；知道怎么开启；知道哪些场景该用、哪些场景不该用。

## 先搞懂：Claude 有几种"动手"的办法

前面几章里，Claude Code 主要是读文件、改文件、跑命令。但有些事不在文件里，而在网页或软件界面里。这时它有三种办法：

| 方式 | 一句话说明 | 用的是谁的登录状态 | 套餐要求 |
|---|---|---|---|
| Claude in Chrome | 通过 Chrome 浏览器扩展，在你真实的浏览器里操作网页 | 你自己的（已登录的网站它都能进） | Pro、Max、Team、Enterprise（需直接使用 Anthropic 账号，不含 Bedrock 等第三方云平台） |
| 桌面应用内置浏览器 | Claude 桌面应用里自带的一个浏览器面板，主要用来看它自己做出来的页面 | 一个干净的空白环境，没有你的任何登录 | 随桌面应用 |
| 电脑操作（Computer use） | 看你的屏幕截图，用鼠标键盘操作任何软件 | 你电脑上真实的桌面 | 仅 Pro、Max；**研究预览**；Team、Enterprise 不可用 |

Claude 会按"从精确到粗糙"的顺序选工具：能用已连接的应用（MCP 连接器）就用连接器，能用命令就用命令，是网页就用 Chrome，实在没有别的办法才动用"电脑操作"。所以电脑操作是**最灵活、也最慢、最需要谨慎**的一种。

## 一、Claude in Chrome：在你的浏览器里干活

### 能做什么

Claude 会新开标签页，在一个可见的 Chrome 窗口里实时操作，并共享你浏览器的登录状态。典型用法：

- 在你已登录的网站上批量录入、填表（比如把一份客户名单逐条录入某个内部系统）
- 从网页上提取信息，整理成表格保存到本地
- 跨多个网站收集资料，汇总成一份文档
- 在在线文档（如网页版文档、邮箱）里起草内容
- 把本地文件上传到网页的上传框（单次上传合计不超过 10MB，需 Claude Code 2.1.211 及以上）
- 录制操作过程为 GIF 动图，用于做教程

遇到登录页或验证码，它会暂停并请你手动处理，不会替你绕过。

### 怎么开启

1. 在 Chrome（或 Edge 等 Chromium 内核浏览器）安装 Claude in Chrome 扩展，版本需 1.0.36 及以上。
2. 用 `claude --chrome` 启动 Claude Code；以后想默认开启，在会话里输入 `/chrome`，选 **Enabled by default**。
3. 输入 `/chrome` 可以随时查看连接状态、重新连接扩展、选择用哪个浏览器。

几点要注意：

- 必须用 `/login` 登录 claude.ai 账号；只用 API 密钥或第三方云平台时，这个功能不可用。
- 扩展要和 Claude Code 登录**同一个组织**，否则会提示"Browser extension is not connected"。
- 在 Windows 的 WSL 环境中不支持。
- 长时间闲置后连接可能断开，用 `/chrome` 里的"Reconnect extension"重连即可。
- 出于安全，它拒绝上传名字像密钥、凭证的文件（如 `.env`、`.pem`，需 2.1.293 及以上）。

### 站点权限怎么管

站点级权限由 Chrome 扩展的设置管理：你可以控制 Claude 能在哪些网站上浏览、点击、输入。第一次在某个网站动手前，会弹出以 `Claude in Chrome wants to` 开头的确认框。

## 二、桌面应用内置浏览器

Claude 桌面应用的 Code 标签页里有一个**浏览器面板**（快捷键 macOS 为 Cmd+Shift+B，Windows 为 Ctrl+Shift+B）。它最常见的用途：Claude 帮你做了一个网页（比如一份报价单页面、一个小工具），自己打开面板，截图、点按钮、填表单，检查有没有做错。它也能打开本地的 HTML、PDF、图片、视频，以及外部网站。

和 Chrome 扩展的区别要记牢：

- 内置浏览器是**干净环境，不带你的任何登录**。需要"以你的身份"操作已登录的网站，请用 Claude in Chrome。
- 第一次访问某个外部网站时，你可以选"允许一次 / 总是允许 / 拒绝"，每个网站（含子域名）要分别批准。
- 点击、输入这类"写操作"会先经过安全检查；它不会替你购物、注册账号或绕过验证码。
- 管理员可以用 `browserExternalPageTools`、`disableBrowserExternalNavigation` 等设置限制它访问外部网页。

> 桌面应用内置浏览器是 2026 年 7 月随桌面应用推出的功能，具体版本要求请以桌面应用的更新说明为准。

## 三、电脑操作（Computer use）

### 它是什么

Claude 通过截图"看"你的屏幕，用鼠标键盘"动手"，可以打开软件、点按钮、输入文字。适合那些**没有接口、没有命令行、只有图形界面**的软件，比如某个专用设计工具、硬件控制面板、模拟器。

目前是**研究预览**，且：

- 仅 Pro、Max 套餐，Team、Enterprise 不可用；
- 命令行版本仅支持 macOS（桌面应用版本支持 macOS 和 Windows）；
- 必须是交互式会话，用 `claude -p` 无界面运行时不可用；
- 不能通过第三方云平台使用。

### 怎么开启（命令行版）

1. 在会话里输入 `/mcp`，找到 `computer-use`，选择 **Enable**（每个项目开启一次）。
2. 第一次使用时，macOS 会请你授予两项权限：**辅助功能**（让它能点击、输入）和**屏幕录制**（让它能看到屏幕）。
3. 桌面应用版本则在 **Settings > This computer > System** 中打开。2026 年 9 月起，桌面应用版在 macOS 上还能在**后台**运行，你可以继续做别的事。

### 它如何保证你能掌控

- **逐个应用批准**：开启这个功能，不等于它能碰你电脑上所有软件。每个应用在每次会话中第一次用到时都会弹窗，你选"本次会话允许"或"拒绝"。
- **分级权限**：浏览器、交易类软件为**只能看**；终端和开发工具为**只能点击**；其他应用才是完全控制。终端、Finder、系统设置这类"权限很大"的应用，批准时会有额外警告。
- **随时叫停**：按 `Esc` 立刻中止。
- **一次只允许一个会话**控制你的电脑。
- 工作时其他窗口会被临时隐藏，结束后恢复。

## 适用场景与风险提示

先看"什么时候该用"：

| 场景 | 推荐方式 |
|---|---|
| 在已登录的内部系统或网站里批量录入、提取 | Claude in Chrome |
| 检查 Claude 刚做出来的网页、报告页面有没有问题 | 桌面应用内置浏览器 |
| 操作没有接口的专用软件、模拟器 | 电脑操作 |
| 有现成的连接器（如日历、云盘、文档） | 优先用连接器（见 [MCP：连接外部世界](/advanced/mcp)），更快更稳 |

再看**风险**，务必在课堂上讲清楚：

1. **它在以"你"的身份行动。** Chrome 扩展共享你的登录状态，它能做的，等同于你本人能做的：发消息、改数据、提交表单。涉及付款、删除、群发的动作，务必自己确认后再放行。
2. **网页内容可能"诱导"它（提示注入）。** 网页或屏幕上可能藏着恶意文字，伪装成指令。官方会检测并提示，但不能保证万无一失。不要让它在不可信的网站上执行高权限操作。
3. **不要放开敏感应用。** 电脑操作中，对终端、Finder、系统设置的批准等于交出很大权限，没有明确需要就拒绝。
4. **录屏、截图可能包含隐私。** GIF 录制会录下页面上的一切，包括登录后的账号信息，分享给外部前先检查。
5. **涉及公司数据要先问规范。** 在网页里处理客户资料前，请对照本教程的 [使用规范与数据安全](/security/)。

## 动手任务

在**不涉及真实客户数据**的前提下，试一次：

```text
请用浏览器打开【某个公开的行业资讯网站】，
找出最近一周与【你的行业】相关的 5 条新闻，
把标题、发布日期、链接整理成一个 CSV 文件保存到当前文件夹。
遇到登录页或弹窗请先停下来告诉我。
```

完成后回看：它新开了哪些标签页？有没有弹出权限确认？你是否能随时中止？

## 小结

- 三种方式分工不同：**Chrome 用你的登录、桌面内置浏览器是干净环境、电脑操作最灵活也最谨慎**。
- 能用连接器和命令解决的，不要动用电脑操作。
- 所有"以你身份行动"的能力，都要配合最小权限、逐步确认的习惯。
