# 场景与行业篇导览

前面几篇讲的是"工具怎么用"，这一章讲的是"拿它干什么活"。每个场景都按真实工作流程拆开：先想清楚分析框架，再用示范提示词跑一遍，最后用课堂练习巩固。

> 本教程为独立编写的培训资料，非 Anthropic 官方内容。章节中的公司、产品、数据均为虚构示意。

## 怎么选场景

先看你手上的活属于哪一类：

| 你要做的事 | 推荐从这里开始 |
|---|---|
| 搞清楚一款产品卖点、客群、顾虑 | [产品调研分析](/cases/common/product-research) |
| 判断一个新市场值不值得进入 | [市场分析](/cases/common/market-analysis) |
| 对比几家竞品、找差异化机会 | [竞品对比](/cases/common/competitor) |
| 写开发信、跟进客户 | [客户开发信与跟进](/cases/industries/trade/outreach) |
| 回复询盘、起草报价邮件 | [询盘与报价回复](/cases/industries/trade/inquiry-quote) |
| 整理目标国家和展会资料 | [海外市场与展会资料整理](/cases/industries/trade/market-exhibition) |

建议顺序：先学三个通用场景（所有行业都用得上），再进入自己所在行业。行业篇是在通用方法上叠加行业习惯，不是另一套东西。

## 怎么用这一章

1. **先读分析框架**：框架是"问题清单"，没想清楚要问什么，提示词写得再长也没用。
2. **复制示范提示词**：把【】里的内容换成你自己的信息，其余保持不动，先跑出一个初稿。
3. **追问和修改**：第一版通常只有七八成，用"再简短些""补充风险""改成表格"继续迭代。
4. **人工核对**：凡是数字、价格、法规、承诺，都要核对来源后再用（见下文）。
5. **沉淀下来**：好用的提示词存进 [提示词模板库](/prompts/)，长期任务放进 [Projects](/basics/projects)。

## 每个场景页的结构

| 部分 | 内容 |
|---|---|
| 分析框架 | 这类任务要回答哪些问题 |
| 示范提示词 | 可复制、可替换【】的完整提示词，并说明输出格式 |
| 课堂练习 / 注意事项 | 动手练习题，以及容易出错的地方 |
| 两种做法对照 | 同一个任务，网页版怎么做、Claude Code 怎么做 |

## 网页版与 Claude Code：什么时候选哪个

| | 网页版（含 Projects） | Claude Code |
|---|---|---|
| 适合 | 资料少（几个文件）、一次性任务、需要来回讨论 | 资料多（一个文件夹几十个文件）、要批量处理、要生成固定格式的文件 |
| 做法 | 上传文件，对话，追问 | 指定文件夹，让它读取全部文件，直接写出汇总表和报告 |
| 优点 | 上手快，不用装东西 | 省去逐个上传，流程可重复 |
| 代价 | 文件多时要反复上传 | 需要安装和熟悉基本操作 |

简单判断：**文件三五个以内，用网页版；文件很多、每周都要重复做，考虑 Claude Code。** 详细用法见高级篇：[Claude Code 是什么](/advanced/what-is-claude-code)、[Skills](/advanced/skills)、[CLAUDE.md](/advanced/claude-md)。

## 三条通用提醒

- **事实要核对**：市场规模、价格、法规、关税等事实性内容，Claude 可能出错或已过时。提示词里要求"标注来源"，再由人去来源核对。
- **只用公开资料**：调研只使用公开渠道的资料。内部资料和客户资料上传前先脱敏，参见 [使用规范与数据安全](/security/)。
- **对外内容必须人工确认**：邮件、报价、承诺发出前，一定由负责人过目。

## 小结

选场景看任务类型，用提示词先出初稿，再追问、核对、沉淀。资料少用网页版，资料多且重复才考虑 Claude Code。
